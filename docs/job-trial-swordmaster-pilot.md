# 剣豪（せんし → けんごう）解放システム 1職パイロット

- 作成日: 2026-10-19
- 状態: **隔離プロトタイプ。mainに統合済み（2026-10-19、PR #121）だが、検証版で `?jobTrial=1` を付けた時だけ有効（`FEATURE_FLAGS.jobTrialSwordmaster`）。正式版未実装、iPhone実機・長期バランス未検証**
- 範囲: 通常ジョブ「けんごう」1職のみ。巡礼剣士の無料公式チャレンジ・有償権利は変更しない

## 遊び方

1. この機能を含む**ブランチの開発/プレビュー配信**で、URLのクエリに `?jobTrial=1` を指定する（通常URLは既存の転職ルールのまま）。
2. `せんし`をLv50まで育成する。
3. 戦士としてダンジョンを**完全踏破**する。成功時にのみ、下記のいずれかが進む:
   - 有効な物理/属性攻撃による実ダメージ **100ヒット**
   - 戦士が生存して完全踏破 **15周**
   - いずれかを満たせば実績達成。累積・アカウント共通のセーブ項目で管理
4. キャラクター詳細 →「ジョブ」→「剣豪の試練（試験モード）」に進み、Lv50の戦士をパーティに含めて**剣豪の試練に挑戦**を押す。
5. 戦闘エンジンで既存敵データの**3戦の試練（最後にボス、各戦闘最大5体）**をフルオート試算。成功すると解放をセーブし、以後転職可。
6. 他キャラも、そのキャラ自身が戦士Lv50を満たせば剣豪へ転職可能。既存のジョブ別Lv/EXPは維持。

## 実績集計

- 手動/通常自動周回: `battle.step`の実際の`damage`イベント（与ダメージ1以上、攻撃者が戦士）からhit数を**run内に暫定集計**し、完全踏破時のみ加算。敗北・中断では破棄
- オフライン周回: 共通シミュレーターは技ヒット履歴を返さないため、**完全踏破1回だけ**集計。実績のためにヒット数を推定・捏造しない
- `run.jobTrialSettled`で同一runの`finishRun`多重呼び出しの実績二重加算を防止
- 永続化: メインセーブ`jobTrialSwordmaster: {warriorHits,warriorClears,trialCleared}`。旧セーブはゼロから開始し、既存の剣豪転職歴があれば解放を保持
- 試練計算: 既存`Runner.computeOfflineRun`を使用。ただし**applyOfflineRunしない**ので通常ダンジョンの踏破/報酬/EXP/図鑑等に反映しない

## 試練設定（仮）

- 起点: 溶岩の大河付近のLv50敵データ
- 3戦、ボス: 灰の獣系（`ash_behemoth`）、道中: `salamander_knight`/`fire_serpent`/`obsidian_golem`
- 装備・スキル・パーティの実際の構成で変わる。クリア率は未計測。難しすぎる/簡単すぎるなら敵・HP/ATK/特性を調整
- 報酬はジョブ解放のみ。試練挑戦の途中に操作要求なし

## 重要な隔離・安全対策

- `FEATURE_FLAGS.jobTrialSwordmaster` は `QPRuntime.channel === "preview"` かつ `?jobTrial=1` の場合のみ有効。productionは常時無効
- 試験モードOFFなら**既存の「基本職Lv50で上級職解放」仕様を維持**。他の5上級職、隠し職、特殊課金ジョブは変更しない
- ローカル実績・試練の結果を**公式サーバー権利の証拠**に使わない。本番で公式解放とするにはサーバー側証明が必要
- 実験のための独立セーブやプレビュー用URL自動生成は未導入。同じブラウザで他のプレイ進行とセーブを共有するので、**テスト専用プロファイルでの体験推奨**
- 将来新旧クライアント混在・多端末セーブ競合・正確な`runId`冪等性については、本番導入前に再設計する。現状のローカルセーブは不正耐性やアカウント間結合の保証にならない

## 最低限の手動確認

1. パイロットOFF: Lv50なら剣豪転職、他5上級職・特殊職は従来どおり
2. パイロットON: Lv50だが実績0では未解放。通常探索が成功すると実績進行
3. 試練: 有効打100回/成功15周でボタン解放、未編成/探索中/非戦士は挑戦不可
4. 試練敗北: 未解放のまま、再挑戦できる。EXP/アイテム/通常踏破が増えない
5. 試練成功: 再読込しても解放が残り、別キャラも自分の戦士Lv50後に転職できる
6. 旧セーブ: 以前から剣豪経験があるキャラの使用権が消えない。通常URLへ戻しても保存壊れなし
7. iPhone Safari/Chrome: ジョブ画面ボタン・長い文面・操作不能・クラッシュがない

## 上級職アコーディオン見出しの簡潔化（2026-10-28）
- 画面の「上級職」カテゴリ見出しは、`上級職（対応職Lv.{JOB_MASTER_LEVEL}で転職）` と表示する。長文説明は表示せず、横幅の狭いiPhoneでも1行固定とする。
- 右端の習得数（例：`0/6`）と折りたたみ矢印を維持する。文字数が増えた場合は見出し部分のみ省略し、操作領域を守る。
- 剣豪に固有の実績・専用試練など、上級職ごとの追加解放条件は各職カード・試練欄で案内し、**見出しの短縮によって判定条件は変更しない**。
- 表示とCSSのみの変更であり、`JOB_MASTER_LEVEL`、`jobUnlocked`、転職処理、保存形式は無変更。
