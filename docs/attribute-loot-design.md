## A. 現行実装とのギャップ（先に把握）

| 項目 | 既存の実装 | 新たに検討・合意した方向性 | 対応区分 |
|---|---|---|---|
| 属性 | 技に「炎・氷・雷・聖・闇」の5種。敵に「火・氷・水・風・土・闇・光」の属性ラベル。互換しない一部名称あり | 基本5＋特殊4＋虚無1＝**10属性** | 移行設計が必要 |
| 相性 | ENEMY_ELEMENT_AFFINITYの個別対応で旧倍率を設定 | 有利/不利の循環・特殊相互有利・虚無と敵/ダンジョンの例外 | 既存戦闘のリグレッションに注意 |

## B. 属性の確定方針

### B-1. 属性ID・相性

属性は10種。以下のIDは**衝突防止のための提案名**（コード実装は未着手）。

| グループ | 表示名 | ID案 | 有利な相手 |
|---|---|---|---|
| 基本 | 土 | earth | 炎 |
| 基本 | 炎 | fire | 氷 |
| 基本 | 氷 | ice | 雷 |
| 基本 | 雷 | thunder | 木 |
| 基本 | 木 | wood | 土 |
| 特殊 | 龍 | dragon | 血塗られた |
| 特殊 | 血塗られた | bloodstained | 龍 |
| 特殊 | 混沌 | chaos | 金 |
| 特殊 | 金 | gold | 混沌 |
| 特殊（万能） | 虚無 | void | 他の9属性（通常時） |

- **基本循環**：土→炎→氷→雷→木→土。矢印は「攻撃する側が有利」。逆向きは不利。
- **特殊**：龍↔血塗られた、混沌↔金。それぞれ攻撃側が相手に有利。ほかの組み合わせは基本中立。
- **虚無**：通常時は他9属性への攻撃が有利。一方でダンジョン効果や敵の耐性・完全無効に左右され、虚無だけで攻略しきれないようにする。「虚無→虚無」は原則中立。
- 現行の「聖・闇」「水・風・光」ラベルからの一括自動置換は**行わない**。旧データの属性名と新10属性の対応を、敵/技単位で調査して移行表を作る。
- 武器シリーズ「虚無」と攻撃属性「虚無」、武器シリーズ「ゴールド」と攻撃属性「金」は**異なるフィールドと識別子**にする。

### B-2. 倍率と処理優先順位（初期比較値・未確定）

| 条件 | 仮の倍率 | 意図 |
|---|---:|---|
| 基本5で有利 | ×1.30 | 特化属性の価値を高める |
| 基本5で不利 | ×0.80 | 対策装備を持ち替える意味 |
| 特殊相互有利 | ×1.25 | 特殊属性の相互対策 |
| 虚無が他9属性を通常攻撃 | ×1.15 | 汎用性はあるが特化に劣る |
| 中立/同属性 | ×1.00 | 基準 |
| 特定ダンジョンで虚無活性/抑制 | 例：×1.40 / ×0.70 | **実際の最終倍率・加算順はプレイテストで確定** |
| 特定敵の虚無強耐性/無効 | 例：×0.50 / ×0.00 | 万能装備の一本化を防ぐ |

**重要：倍率表の「×1.40/×0.70」は仮の見せ方。** ドロップ・敵HP・武器ステータスと一緒に最終ダメージを検証してから、環境補正を「相性倍率の置換」か「別乗算」か統一する。無条件に全倍率を掛け算すると極端な結果を生むため、テストケースを先に決める。

### B-3. 効果判定の安全な順番（設計提案）

1. 攻撃属性を決める。通常攻撃は装備属性、技は技の明示属性優先を初期案とする（バフによる上書きは後で整理）。
2. 敵が**完全無効**なら原則0倍を返す。一般の属性反転/耐性貫通で無効を解除できない。
3. 基本/特殊/虚無の相性を取得する。
4. ダンジョン環境と敵の個別耐性を評価し、順序・重複時の上限を適用する。
5. 武器の属性反転等のOPを適用する。**不利→有利は原則指定した1属性との相性のみ**。完全無効より優先しない。
6. 最終倍率と適用理由を戦闘ログ/自動戦闘AIへ渡す。0倍しか出ない攻撃をAIが選び続けない。

実装時は属性計算だけを純粋関数化し、10×10属性表、虚無活性/抑制/完全無効、属性反転、通常攻撃/技属性の整合をテストする。

### B-4. 最初に試したい対決

| 攻撃側 → 相手 | 通常の予測 | 特別条件 |
|---|---|---|
| 炎 → 氷 | 有利 | なし |
| 炎 → 土 | 不利 | 「対土反転」OPで有利に変えられる |
| 龍 ↔ 血塗られた | 両方向で有利 | なし |
| 混沌 ↔ 金 | 両方向で有利 | なし |
| 虚無 → 炎 | 有利だが基本特化より倍率控えめ | なし |
| 虚無 → 任意属性の耐性ボス | 不利/無効になり得る | ボス固有の耐性を優先 |
| 虚無 → 虚無 | 中立 | ダンジョンの虚無補正を別途判断 |

## C. 装備収集の確定方針

### C-1. 収集の4つの価値軸

1. **武器レアリティ**：N/R/SR/UR/LR（本体の基本性能・継承先の成功率/枠数）。
2. **天然オプションのレアリティと数値**：武器レアリティとは独立。例：N武器から希少な会心OPが出る可能性を残す。
3. **属性・シリーズ・種類**：同じレア度でも有利なダンジョンとビルドが変わる。
4. **固有効果と入手場所**：固有装備・呪い/条件付きシリーズ・特殊ボスOPなど、周回目的を分散する。

収集ループ：ダンジョン周回 → 自動分解/保護の選別 → 天然OPを見極める → 必要なら抽出（武器は残る） → 上位装備の強化/穴あけ → 継承 → 対象ダンジョンで実戦比較 → 別ビルドを探索。

### C-2. シリーズ・武器名・装飾品カテゴリ

**相談で出たシリーズ候補（本体に全部実装済みという意味ではない）：**
アイアン、ブロンズ、ゴールド、プラチナ、メタル、スチール、ミスリル、ドラゴン、ホーリー、アビス、豪爆、轟混、虚なる、魔ぜる、耀妖、常闇、失墜、虚無、呪い系（血塗り/墜落/邪眼/愚かな）。

- 新シリーズをすべて通常ドロップ表に同時投入すると、1種類あたりの出現率が下がり厳選が辛くなる。**通常の地域シリーズ、ダンジョン限定シリーズ、固有/呪い系**に分けた入手設計を先に決める。
- 武器の候補：ソード、ダガー、ブレイド、ワンド/ロッド、アクス、サイス、スピア、クロー、拳銃、ボウ、素手。**素手は装備なしの戦闘スタイル**案。現行の大剣・メイス等との対応は未確定で、即削除しない。
- 装飾品は**指輪、ブレスレット、イヤリング、その他**の4カテゴリを持ち、それぞれシリーズ型と固有型を用意する。ただし**装備スロットは現行の最大3枠を維持する方向**。既存の「靴・お守り・ブローチ」を「その他」に集約する場合も、旧セーブと装備中アイテムを失わない移行が必要。

### C-3. 天然OPと穴あけの競合（要重点レビュー）

**既存の大きな矛盾：** 現行のハード/エクストラ装備は天然OPが1〜3個付く。しかし試作の設計では最大OP数がN1/R1/SR2/UR3/LR4。しかも穴あけで「後付けする枠」を解放する。

実装前の推奨（**暫定、体感前に最終確定**）：

- 天然OPはドロップ時に付く。**天然OP数＋継承OP数は武器レアリティの最大OP数を超えない**。
- 解放済みの穴の数は**後付けの継承OP数の上限**とする。例：SR+50は継承OP最大1、SR+99は最大2。ただし既存の天然OPが1つあれば、SR+99でも追加できるのは最大1つ（合計2）。
- 天然OPがある武器であっても、後付け枠を使えるまで強化/穴あけの操作が必要。不要な天然OPを抽出すれば本体の容量が空く。
- ドロップ時のOP付与数は **min(モードごとの抽選数, レアリティの最大OP数)** などで抑える。N/Rに3個の天然OPが入らないようにする。
- 天然OPを複数持つ武器からの抽出は、取り外すOPを1個選ぶ。他の天然OPと武器本体は維持。
- 継承素材は **{key, value, optionRarity, sourceItemRarity, origin, bundleId}** のように効果の実数値まで保存する。試作工房の固定OP表示だけでは実ドロップの {key,value} を失うため、必ず拡張する。
- 同じ種類のOPの重複付与を禁止。属性反転などの**特殊OPは最大1個**。強化した分の数値は上書きや品質アップで勝手に増えない。

このルールにより「SR+99の空武器にOP2個を後付けできる」という会話上の想定と、天然OPありの収集価値を両立できる。

### C-4. 継承リスクと抽出液

| 継承先 | 継承元のレア度 | 通常継承成功率 | 天井 | 最大OP総数（暫定） |
|---|---|---:|---|---:|
| N | なし | — | — | 天然1 |
| R | N | 100% | 不要 | 1 |
| SR | N・R | 100% | 不要 | 2 |
| UR | N・R・SR | 65% | 2失敗→次回確定 | 3 |
| LR | N・R・SR・UR | 45% | 3失敗→次回確定 | 4 |

- 下位から上位への直接継承可。Nの希少OPが最終装備の素材になり、N収集が腐りにくい。
- 抽出は100%成功、武器本体は消えない。天然OPだけを取り外す。**継承済みOPは再抽出不可**。
- 抽出液の個数はOPランクで N=1/R=2/SR=3/UR=5/LR=8（暫定）。1抽出→1継承分の束であり、増殖不可。
- 試行失敗時は液体を消費して武器・既存OP・穴は維持。
- 確定継承液はUR/LRで1回の継承を100%成功にする課金候補。**試作の無料テスト配布は商用の無料入手ルールを意味しない**。
- 課金液使用の成功では既存天井カウントを変更しない。天井到達時に確定液を使用させない。

### C-5. 掘り続ける理由を作るドロップの分離（提案）

| 周回先 | 狙うもの | 調整ポイント |
|---|---|---|
| 通常の進行ダンジョン | 現レベルに合った武器本体・シリーズ | 進行を止めない、序盤から選ぶ楽しさ |
| ハード/エクストラ | 高品質な天然OPの付いた武器 | 現行ルールとの整合、Nでも良OPを掘れる条件 |
| 属性特化ダンジョン | 属性シリーズ、反転など希少な天然OP | ボス耐性と収集需要を結び付ける |
| 特殊/期間限定ボス | 固有武器、希少な対策OP | 他装備の価値を無効化せず、新しい目標を追加 |

**自動分解の注意**：現在の自動分解は主にレア度ベースなので、N装備を自動分解すると希少OPも失われる。天然の高レアOP/特殊OPがある武器は保護するフィルタを、入手バランス調整と同時に設計する。

**ドロップ供給の注意**：虚無武器や属性反転OPが常に低レベル通常ダンジョンで出ると、属性対策の価値が落ちる。出現率・ダンジョン条件・OPランク・序盤の戦闘バランスを分けて設計する。

## D. 次のプロトタイプ検証順（実装はこれから）

1. **属性データの独立設計**：10種のキー、相性解決関数、敵耐性、ダンジョン環境、技/通常攻撃の属性を整理。旧「聖・闇・水・風・光」をどのように残す/移行するか一覧化。
2. **ドロップとOPデータの整合**：天然OPの最大数、希少OP出現条件、抽出液へ引き継ぐ {key,value,rank}、自動分解の保護条件をテスト。
3. **代表3ビルドで比較**：(a)虚無中心の汎用装備、(b)基本属性の特化、(c)属性反転OP入りの対策装備。通常/虚無抑制/虚無無効の3ダンジョン条件で比較。
4. **数値バランスの調整**：1周の所要時間、狙いのOPが出るまでの周回、UR/LR継承に必要な抽出液の消費、装備持ち替えの意味を確認する。
5. **本体へ段階適用**：セーブ互換・装備制限・戦闘AI・既存ジョブ/敵の回帰検証を通してから、実ゲームで操作テストする。

## E. 現時点で決め打ちしない事項

- 倍率の最終値と、敵耐性×環境補正×OP補正の合成順。
- 虚無が活性化/抑制するダンジョンと、耐性敵の具体的な配置。
- 新シリーズを通常ドロップ、限定ドロップ、固有装備のどれに置くか。
- 天然OPが付くモード・抽選数・各ランクの出現率。現行のハード/エクストラ付与だけでよいか。
- UR/LRの穴あけ条件や素材費用。強化自体は既存では全レア+99。
- 武器属性と魔法スキル属性の優先規則、および現行「聖」「闇」技の移行。
- クラフト結果のUI詳細、ガチャ的な演出、商品の販売価格。

この未決事項をテスト結果を見ながら決める。プレイヤー向け未公開予定へ自動転記しない。
