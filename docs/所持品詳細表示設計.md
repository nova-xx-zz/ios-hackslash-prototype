# 所持品詳細表示設計

## 目的
- iPhoneの所持品一覧から、ロックや強化操作をせずに各武器・防具・装飾品の詳細を確認できるようにする。
- 一覧のレア度順・保護表示・強化する・装備分解の既存機能は変更しない。

## 画面
- 各装備行に **ⓘ** ボタンを追加。並びは「装備アイコン／名称・OP／ⓘ／ロック／強化する」。
- 幅が狭いiPhoneでもⓘのタップ領域は約32×34px、ロック・強化ボタンを残す。
- ⓘで専用の読み取り専用モーダルを開き、装備名、レア度、部位・種類、Lv、強化値、装備能力値、追加オプション、固有効果とフレーバー（該当時）、保護状態を表示する。両手装備は「両手」を追加。
- 現在のスキルブックは鑑定・使用未実装のため、ⓘ追加の対象外。
- モーダルは「とじる」、背景タップ、Escapeで閉じられる。開く前のボタンへフォーカスを復元する。

## 既存ロジックを再利用
- `itemLabel`、`rarityColor`、`itemStatsText`、`itemOptionsText`、`itemEffectText` を使用し、同じ装備能力値の計算・フォーマットを維持。
- `S.inventory`や保存形式に新しいデータは加えず、モーダルを開くだけでは`scheduleSave`しない。
- 装備分解の選択中・ロック中もⓘで閲覧可能。ⓘのクリックではイベント伝播を止め、分解候補の選択状態を変更しない。分解確定ボタンも詳細には置かない。
- 詳細ダイアログの文字はすべて`textContent`で表示し、アイテムデータをHTMLとして挿入しない。

## 実装対象
- `js/ui/inventory.js`：ボタンと専用モーダルの表示／閉じる処理
- `index.html`：アクセシブルなモーダルとCSS/JSの読込
- `css/inventory-detail.css`：所持品専用スタイル
- `tests/inventory-ui-management.test.js`：閲覧時の非破壊、選択状態保護、モーダル構成
