# 所持品詳細・鍛冶屋シート設計

## 方針（2026-11-02改定）
所持品の通常一覧は「装備アイコン／名前・能力・OP／最右端のⓘ」に統一する。ⓘの四角い装飾枠は撤廃し、透明の44×44pxタップ領域を確保。ロック・強化ボタンは一覧から撤去する。

## 装備詳細（鍛冶屋）
- ⓘで画面下からせり上がる鍛冶屋シートを表示。背景タップ・×・Escapeで閉じる。
- 装備名、レア度、部位・種類、Lv、強化値、能力値、オプション、特殊効果、保護状態を従来の表示関数から取得。
- 鍛冶屋のアクションは「ロック/解除」「強化する」「分解する」「OP付与（準備中）」。
- iPhoneの安全領域・スクロールに対応し、アクションを下部に固定する。

## 各アクション
1. ロック：既存Inventory.setLockedを呼び、scheduleSave()と一覧更新。ロック装備は分解不可。
2. 強化：従来のopenEnhanceModal()を再利用し、鍛冶屋から呼び出した場合だけ下部シートで表示。終了後は装備詳細へ戻る。
3. 分解：下から2段目シートを表示し、対象名・獲得強化石・取り消し不可を示す。通常品は確定操作で分解。貴重品はさらに1段階の明示確認。ロック装備は実行不可。Inventory.disassembleItems([item])を利用し、成功時のみsaveGame()、一覧再描画、取得石メッセージを出す。
4. OP付与：2段目の下部シートで「準備中」を明示。現段階では操作や素材消費を実装しない。将来のOP抽出・継承・付与の設計を追加する場所として確保。

## 既存機能の維持
- 一括分解は従来どおり一覧上部の「分解する」から実行可能。
- 分解選択モードで行を押すと選択／解除。ⓘはクリック伝播を停止し、選択状態を変更しない。
- 所持品に存在する同一参照のアイテムだけを鍛冶屋で加工。装備中・既に削除された装備には操作しない。
- 操作後は一覧のスクロール位置を維持し、セーブ形式は変更しない。
- 未鑑定スキルブックは詳細の対象外。

## 実装
- js/ui/inventory.js：一覧ⓘ配置・鍛冶屋操作・分解確認・強化画面復帰。
- index.html：鍛冶屋と2段目のシートDOM。
- css/inventory-detail.css：iPhone下部シート・ロック/強化/分解/OPボタン・余白。
- tests/inventory-ui-management.test.js：非破壊表示、個別分解、貴重品、ロック、分解選択、構成。
