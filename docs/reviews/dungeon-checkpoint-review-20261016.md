# 3F・5Fダンジョン：同一周回チェックポイントの設計・RV

> 2026-10-16 / PR #105 / 試験URLのみ / 通常版・本番版への無条件適用禁止

## 目的と不変条件

- iPhone Safari / Chrome の再読み込み・タブ休止・アプリ切替後も、**既存のrunを途中から再開する**。入場時に抽選した全階層の通常戦闘数を引き直さない。
- 同じ戦闘の敵HP、味方HP/MP、ATB、ボスフェーズ、戦闘中のバフ/デバフ、乱数系列を復元し、リロードによる有利な再抽選を発生させない。
- **最終ボス撃破での完全踏破のみ**未確定装備の持ち帰り可。全滅・timeout・撤退はUR/LR・宝箱を含め全ロスト。途中のボス/イベントでは精算しない。
- 既存の通常版セーブは変更しない。試験URL `?dungeonPilot=1` の既存分離領域 `qpdungeonpilot:` だけに任意の `pilotRuns` フィールドを追加。
- 当該モードは Firebaseクラウド同期無効。プロダクションのruntimeでは試験フラグを有効化しない。

## 既知の制約・未完了

1. pilot URLのみのローカルcheckpointであり、サーバーでの勝敗・報酬署名・チート対策は未着手。
2. 自動周回中にページが再読み込みされた場合、同一runは再開するが、**連続周回は安全のため停止**。ユーザーが再度周回開始する。ページを破棄せずバックグラウンドから戻った場合は継続する。
3. 戦闘中の保存は定期保存・ページ非表示時・戦闘開始時に行う。直前の保存より後の数刻みは端末クラッシュ時に巻き戻る可能性がある。将来の正確なトランザクション保証はサーバー側に移す。
4. データ破損でrun部分だけ復元できない場合、以前から所持していた装備は保持するが、進行中の未確定アイテムの回収は保証しない。壊れたrunをクリア扱いにすることはしない。
5. 盗賊解錠スキルの正式な習得・スキルツリー統合は次工程。10F/15F・中ボス実装もまだ別工程。
6. 実機の完了報告・CI成功確認までは**本番適用を保留**。
