# 洞窟5F：僧侶2名＋盗賊の編成比較（実戦闘・各240周）

> 2026-10-16 / ソードクレスト3F/5F試験ブランチ（main未反映）
>
> 実測記録: [Cave party composition experiment #38894628859](https://github.com/nova-xx-zz/ios-hackslash-prototype/actions/runs/38894628859)
>
> 再現用: [tools/cave-party-comparison.js](../../tools/cave-party-comparison.js)
>
> 本資料は**ユーザー提案の5人編成が難易度に与える影響を調べるもので、ゲームの敵能力・ドロップ・ロスト・セーブ形式は変更しない**。

## 仮説

「初期ジョブだから勝ちづらい」のではなく、「初期5人のジョブ構成が長丁場の5Fに不利」。提案パーティは **剣士1・僧侶2・盗賊1・魔法使い1**。同じ初期ジョブのまま役割を再配分し、回復役2名と解錠術を両立する。

## 条件と比較の公平性

- 洞窟Lv7、NORMAL、5人固定。同じ装備ビルド・同じLv・同じ初期種族配置（human/beastkin/sylvan/nocturne/stonekin）・同じ固定seed範囲91027000〜91027239を使用。
- 実エンジン: `Runner.computeOfflineRun` / `battleCore.simulate` / 5F階層計画 / ボス60%フェーズ / 泉 / 盗賊Lv5解錠 / ドロップと失敗全ロスト。
- 装備ビルド: 適正装備＋スキルツリー、さらに+4、さらに理想的厳選OP。各編成×3装備×2難易度×240回＝**5,760回**。
- 条件間で乱数シードは同じ。ただし攻撃/回復・解錠で乱数消費数が変化するため、厳密な「敵とイベントが全周回で同じ」ペア検定とはならない。**差を全て僧侶だけの効果と断定しない**。

## 解錠・報酬経済（調整前・適正装備）

- 提案編成：鍵付き宝箱330個を発見、解錠成功146回。宝箱を発見する回数や解錠判定回数は編成による進行差で変わるため、鍵付き宝箱の総数が全編成で一致するものではない。
- 提案編成の持帰り装備（N自動分解後）は挑戦あたり平均6.40個、強化石73.69個。
- 初期編成は持帰り装備平均4.01個、強化石43.98個。**踏破率向上と盗賊解錠で持帰り量が大きく増える**ため、今後のアイテム/石供給の再評価が必要。
- **失敗周のドロップ確定は全比較条件で0**。UR/LR・宝箱を含め、中途確定しない。

## セルフRV（ゲームデザイン／戦闘／報酬／QA）

1. **ゲームデザイン:** 仮説は強く支持される。問題は「初期ジョブそのもの」より**初期編成が長期探索に不向き**だったこと。ヒーラー2名の改善が大きいが、盗賊1名による攻撃・素早さ・敵処理順の変化も同時に起きており、因果効果を分ける追加実験の余地がある。
2. **戦闘／編成バランス:** もとの5F通常敵倍率1.0でも提案編成95.83%、+4/OPで97.08%。**僧侶2人が事実上の必須編成になっていないか**を他編成・ジョブ・難易度で検証する。強化値のみの効果はどの編成でも小さく、別途強化式を点検する。
3. **報酬経済:** 高踏破編成は、ロストのリスクは維持しながら装備と石の持帰り期待値を増やす。報酬の「確定ドロップ数」と「分解後に残る装備数」の区別を徹底する。理想的装備や盗賊込みの時給でインフレしないか、次の調整工程で確認する。
4. **QA／統計:** 実エンジン・同レベル・同種族配置・同装備・seed範囲で再現できる。ジョブ入替によって戦闘数やRNG消費が変わるため厳密な1試行ペアではない。240周は35ポイントの大きな差を確認するには十分だが、1～2ポイントの小さな差を断定できない。iPhone操作の検証と、複数チーム・オフライン再開はこの実験自体では未実施。

## PR #108（通常敵20%弱化）への重要な再レビュー

従来の実験は**初期編成のみを基準に、適正装備での踏破率を85%以上へ近づけようとしたもの**。今回の比較により、編成を工夫するだけで旧倍率でも95.83%を踏破できることが判明した。

**提案：PR #108の通常敵20%弱化は直ちにmainへマージせず、見送りまたは巻き戻しを検討する。** 弱化した状態では僧侶2名を用いる提案編成が98.33%、僧侶2名・盗賊なしが99.58%となり、序盤から装備/OP厳選やパーティ構築の手応えが薄れる可能性がある。

ただし、初期編成の60.83%が理不尽なら、洞窟の案内に「回復役2名」「別編成での攻略」を示唆するか、選択肢が増える設計をする。敵倍率を一律緩和する前に**パーティ編成による攻略体験を評価する**。この結論は調整案の再評価であり、本PRには敵数値変更を含めない。

## 次に優先する項目

- 戦闘ログから僧侶ごとのヒール発動回数、累積回復量、MP枯渇の位置を計測して、ダブル僧侶の強さが「高い回復量」か「行動順・生存性」かを分離する。
- 3F～5Fの難易度表示／推奨編成のヒントを設計。必須ジョブを作らないよう編成自由度と一次職の価値を維持。
- 強化+4のみの効果が薄い原因を`itemStats`・丸め・戦闘ATB/DEF計算で確認。
- 石・装備ドロップの1周あたり・ゲーム内10分あたりの供給見積もり。
- 本番環境にはマージせず、PR間の依存関係を整理してから機能ゲート解除を判断。
