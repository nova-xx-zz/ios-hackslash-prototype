# ダンジョン・ボス設計 セルフレビュー記録（2026-10-16）

> 対象: [ダンジョン・ボス設計 v0.1](../dungeon-boss-design.md)
>
> 実施方法: **同一AIによる4つの専門観点の独立したレビュー・パス**。実際に4つのAIエージェントを起動したものではなく、人間や別モデルによる独立承認でもない。既存GitHubコード・設計書を読み、仕様と衝突点を確認。**実装・UT・IT・実機テストは未実施**。

## 要約

- 原則「攻略失敗時はUR/LRを含め未確定品をすべてロスト」「中ボスでは確定しない」「自動周回中に入力を要求しない」を変更せず維持。
- 重大な設計リスクのうち、ボスを含めた最大敵数、召喚による無限報酬、原子的な報酬確定、失敗ログの保存量を本文へ反映。
- 35ダンジョンのボス割当、実際の数値調整、旧run保存からの移行、オンライン/オフラインの結果差は**実装前の未解決事項**。

## 観点A: ゲームデザイン／報酬経済

| ID | 重要度 | 指摘 | 対応 |
|---|---|---|---|
| GD-01 | P1 | 15階層は平均55.5回の通常戦闘+3ボス。失敗時に全ロストのため、体感時間と攻略可能性が悪化する恐れ | ロスト救済はせず、難易度・時間あたりの装備供給・ログからの攻略可能性を受入条件へ。**計測待ち** |
| GD-02 | P1 | 新しい長期周回で旧1周3～5戦基準の強化石・UR/LR供給・x100課金価値が変わる | 時間/踏破率ベースの収支を検証。旧経済数値の無条件流用禁止。**計測待ち** |
| GD-03 | P1 | 失敗後に攻略の糸口が見えなければ、厳しいロストが理不尽に感じられる | 予兆・効果・対策の手掛かりと失敗後の直近run要約を追記。**設計対応済み／UI未実装** |
| GD-04 | P2 | 中ボスの固定UR/LR報酬でレア装備価値が薄まる | 固有装備・UR/LRの保証は作らない。**設計対応済み** |

## 観点B: バトルエンジン／状態遷移

| ID | 重要度 | 指摘 | 対応 |
|---|---|---|---|
| BE-01 | P1 | 現行buildEncounterは通常敵最大5体+ボス1体で6体になり得る | ボス・召喚を含め同時敵数最大5体をMUSTに。**設計対応済み／コード未修正** |
| BE-02 | P1 | ENEMY_BATTLE_GROWTH=0.06を55戦超に適用すると極端な難易度上昇 | 階層深度ベースの上限付き補正案を明記。**数値検証待ち** |
| BE-03 | P1 | 現行performEnemyActionは通常攻撃のみ。特殊技をログに書くだけではフェーズが存在しない | BattleActionの共通ロジック・フェーズ一度限りトリガー・offline共用を必須化。**実装待ち** |
| BE-04 | P1 | 召喚敵を何度でも倒すことで報酬稼ぎ／無限ループ／時間切れが起こる | 召喚回数/同時数を制限。召喚敵の個別報酬・EXP・テイムを禁止。取り巻きを含めて勝利判定。**設計対応済み** |
| BE-05 | P2 | HP一撃で60/30%両方を超えた際の二重移行、死亡後の技発動 | 一度だけのトリガー管理と死亡優先を明記。**設計対応済み** |

## 観点C: セーブ／不正・課金境界

| ID | 重要度 | 指摘 | 対応 |
|---|---|---|---|
| SE-01 | P1 | リロード／多重イベントで報酬を二重取得、またはsettledのみ先に保存して報酬消失 | 同一run冪等性と「settle+completeの原子的保存」を要求。**実装待ち** |
| SE-02 | P1 | クラッシュをゲーム敗北と誤認してロスト、または復元時に乱数再抽選 | 同一run復旧と敗北ロストを分離して明記。現行の起動時復元は未完成なので**方針確定待ち** |
| SE-03 | P1 | クライアントセーブだけで悪意のあるクリア偽装を防げない | サーバー権限/課金権利台帳とゲーム結果を分離。ローカル保存に完全な不正防止がないと明記。**将来対応** |
| SE-04 | P2 | レア報酬や中ボス装備が、進行途中で所持品に入るとロストの例外になる | pendingDrops一元管理・最終ボスのみ確定。**設計対応済み** |

## 観点D: QA／回帰・パフォーマンス

| ID | 重要度 | 指摘 | 対応 |
|---|---|---|---|
| QA-01 | P1 | 画面・自動周回・オフライン精算のロジック差でロスト・EXP・ボスフェーズが食い違う | 同一ルールの採用と3経路比較テストをMUSTに。**テスト未実施** |
| QA-02 | P1 | 旧run.battleIndex、dungeon.battles、旧boss判定が残存してバグを起こす | 旧参照の全検索・互換アダプタ・回帰テストを要求。**実装待ち** |

| QA-04 | P2 | 10属性/虚無は独立試作のみで、新ボスが先に前提として使うと勝てなくなる | 現行属性のみで初期試作。拡張はfeature gate後。**設計対応済み** |

## 修正による設計反映

1. 3.3.1 に「召喚込み最大5体・取り巻き撃破まで勝利しない・召喚敵からの無限報酬禁止」を追加。
2. 3.5 に「失敗ログ要約の保持・テキスト全文の無制限保存禁止・攻略のヒント」を追加。
3. 4 に「run報酬の原子的確定・同一runの安全な再開とロストの区別・クライアント不正耐性の限界」を追加。
4. 7 に「冪等性・原子的保存の受入条件」を反映。
