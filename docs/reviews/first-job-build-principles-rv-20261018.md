# 設計セルフRV: 一次職252編成と二次職時短（2026-10-18）

> 対象: [一次職全編成攻略・ダンジョン／スキル設計](../first-job-all-party-dungeon-design.md)。本PRは**ドキュメント専用**。Normal/Hard/Extraが全構成で攻略できることを実証したレポートではない。

| ID | 観点 | 所見 | 判定/次アクション |
|---|---|---|---|
| RV-01 | 「全職編成」と「全部簡単」の混同 | 252通りの各編成に複数の勝ち筋を作り、効率・育成コストは違ってよいと区別 | 原則は確定 |
| RV-02 | 物理/魔法/聖の無効で一部PTが永続的に詰む | Extra 0倍を突破する全職共通のダメージ種別/聖属性経路が未整備 | **P0・対抗経路実装まで全編成Extra達成とみなさない** |
| RV-03 | OP入手時期の循環 | 現行OPは主にHard/Extra入手。Normal踏破にHard/Extra専用品を要求すると矛盾 | **P0・前地域Normalで入手できる代替を明示** |
| RV-04 | 装備強化と育成経済 | 強化石・レア度・オプションの理想上限をベンチマークにすると「実際には作れない攻略ビルド」になり得る | **P0・進行シミュレータと取得量で費用上限を裏付ける** |
| RV-05 | 同職5人の極端構成 | 5僧侶は火力、5魔法使いは物理耐性・生存、5戦士は魔法種別の入口が課題 | **P0・6職の同職5人を代表シナリオ化** |
| RV-06 | Lv上限 | キャラLv99に対し最後のダンジョン推奨Lv100。Lv100達成必須にすると到達不能 | **P0・Lv99以下と事前入手可能な装備を条件にする** |
| RV-07 | ブック切替 | 将来のスキルブック初回ロック・2回目の消費で対抗スキルが封鎖され得る | **P1・消耗品の再入手/通常攻略の代替策を事前確認** |
| RV-08 | 二次職の価値 | 単純に無条件の強化を付けると一次職価値がなくなる。ゲーム内秒と同コスト比較が必要 | **P1・10〜25%は仮目標、未実測** |
| RV-09 | ボス・10/15F | 特性持ち1〜3体のスポーン検証は攻略成功を保証しない。ボス取り巻き＋MP消耗や全滅ロストが効く | **P0・実戦闘/ボス/長期周回の検証必須** |
| RV-10 | 元設計との整合 | 既存スキルツリーの「初期PT85%」「Extra最適4PT88%」は新しい252構成基準と別物 | 履歴として保持し、新設計を上位に参照 |
| RV-11 | 自動周回UX・セキュリティ | 泉のタップなど途中入力を要する攻略は不可。課金・サーバー有償残高は変更しない | コード変更なし、次PRで操作導線を確認 |

## セルフRV結論

- **設計の方向性: 採用。** 同職含む一次職全編成に勝ち筋を用意し、二次職は時短・安定性で差を付ける。
- **実装・全編成攻略・バランス数値の合格: 未判定。** 旧テストや少数の仮想装備がクリアしただけでは合格にしない。
- **次のエンジニアリング工程:** 無課金入手可能な「ダメージ種別/聖属性/持久力」代替手段の仕様→現行battle/AI/OPへの適合→偏りPT実戦闘→各ダンジョンの対応。
- Draft PRで設計のみ保存。既存ユーザーのセーブ・レアドロップ・強化・課金・敵倍率・スキル性能・実ゲーム挙動を変更しない。
