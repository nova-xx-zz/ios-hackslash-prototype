# 全ジョブ統合スキルパネル設計

## 目的と適用範囲
- プロトタイプで検証済みの戦士用「六角形の統合パネル」を、基本職6・上級職6・特殊職1の**人間ジョブ全13種**に展開する。
- 対象は JOBS の tier=basic/advanced/special、EXCLUSIVE_TREES の既存7系統。モンスターは別の職業データ管理であり、今回の対象外。
- 固有17ノード＋汎用Ⅰ〜Ⅲの各6ノード＝35パネル、覚醒Ⅰ〜Ⅲの予約領域を各職業に表示。未実装の覚醒操作や状態・保存は追加しない。
- すべてのジョブで剣・体・盾・足・腕・杖の既存アイコン分類と、分岐チップの見切れ対策を共通使用する。

## 表示の切替・UIの初期値
- 戦士は直前の比較試作と同様に既定を旧紋章盤とし、切替で統合盤を選べる。既存の検証動線と旧画面比較を維持。
- **戦士以外の12ジョブは統合盤を初期表示**。統合盤右上「旧盤面」で従来表示に切替でき、旧盤面から「統合パネル」へ復帰可能。
- モードはジョブごとのメモリ上の一時UI設定であり、セーブデータには書き込まない。ジョブを切替えても他ジョブのモードに干渉しない。
- 仲間やジョブを切り替えたらフィルター・選択ノードを初期化し、異なる職のスキル選択を持ち越さない。
- 戦士は剣撃突き(w3)を選択。他職は習得済みのアクティブ技→最初のアクティブ技→先頭ノードの優先順で詳細を表示。

## 正本とゲームロジック
- 固有スキルマスター EXCLUSIVE_TREES、汎用3枠 GENERAL_SLOTS、習得条件 canAcquireNode、実際の習得 acquireNode、二択確認・SPと強化石・リセット・交換・保存処理は変更しない。
- パネルの隣接は解放条件ではない。二択は exclusiveGroup と取得済みランクで決定し、元の習得処理を使う。
- 既存の六角枠・選択状態・色・アイコンをそのまま使用し、各職の固有ツリー名と技名のみマスターデータに従う。
- 固有ツリーのノードが増えても欠落させず、追加行に収容する。

## 改修範囲と検証
- js/ui/detail-tree.js: 全ジョブで共通画面を選択できる条件・ジョブ別モードを追加。
- js/ui/skill-panel-unified.js: 戦士専用名の関数を汎用化し、職業別の初期選択を追加。
- css/skill-panel-unified.css: CSSの共通適用範囲を明示、実際の描画サイズは維持。
- index.html: CSS/JSのキャッシュ番号更新。
- tests/warrior-unified-skill-panel.test.js: 全13ジョブ・固有スキル・汎用・覚醒予約・二択・習得・切替・フィルター・キャラ送りを確認。
- GitHub Actionsで全自動テストとWebリリースビルドを確認後にマージする。
- iPhone Webでの視覚確認はマージ後。低レベル・SP不足・チップ・画面内スクロール・下部詳細ドック・特殊職の文字折返しを確認する。

## 現時点の非対象
- ジョブ覚醒Ⅰ〜Ⅲの解放処理、専用試練、職業ごとのパネル追加、スキルマスター変更、モンスター職、正式版リポジトリへの移管。
