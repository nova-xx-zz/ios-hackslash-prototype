# スキルの二択UI設計

2026-10-26 / 対象: プロトタイプ版 `ios-hackslash-prototype` / ブランチ `feature/skill-choice-ui`（**ユーザー確認前・未マージ**）

「どちらか1つだけ習得できるスキル」（データ上の `exclusiveGroup`）の表示を、全職の固有ツリーと汎用ツリーで共通の仕組みとして設計する。ゲームロジック（`canAcquireNode`・`acquireNode`・排他判定・リセット）とセーブ構造は変更しない。

## 1. 背景と課題

- 二択は **固有ツリー7職すべて（各3組）と汎用ツリー6本すべて（各1組）** にある。どの組も「同じ親から分かれる2つ」。
- せんしの紋章盤では、組の2つが猛攻（右上）と鉄壁（左下）という盤面の反対側に置かれ、組だと分からなかった。
- 選ぶ前は両方とも「習得可能」の金色で、二択だと分かるのは詳細の小さな「二択 ○○」だけだった。片方を取ってから初めてもう一方が封印されたと気づく。
- 猛攻・鉄壁の方向に並ぶ3つは前提でつながっておらず、3つの二択は互いに独立している（1段目は攻め・2段目は守り、のような選び方ができる）。方向に並んでいるため一続きの道に見えてしまう。
- 選び直しにはツリー全体のリセット（強化石）が必要なのに、1回押しで確定していた。

## 2. 表示のルール（全ツリー共通）

| 要素 | 見た目 | 意味 |
|---|---|---|
| 割符の印 | ノード右上の丸い札に番号（Ⅰ・Ⅱ・Ⅲ…） | 同じ番号の2つが1組。盤面の離れた位置にあっても組だと分かる |
| 分岐の門 | 親ノードに付く菱形の札（同じ番号） | ここから二択に分かれる |
| 二択の線 | 親から組への線を点線にする。親を習得済みで選べる時は金の点線 | まだ選んでいない分かれ道 |
| 相方の強調 | 組の片方を選んで見ている時、もう一方に金の点線の輪が脈打つ。組の2本の線も太く | 比べる相手がどこにあるか |
| 選んだ後 | 選んだ側の札は金で塗りつぶし。選ばなかった側の札は錆色の点線、ノードは封印（鎖） | 確定した結果 |
| 途切れた線 | 選ばなかった側の線は親側4割を消し、切れ目に×印（紋章盤のみ） | もう通れない道 |

- 番号は各ツリーの中で、データの並び順に Ⅰ から振る（せんし: 不動/猛攻の構え＝Ⅰ、鉄壁の構え/豪腕＝Ⅱ、闘志/覇気＝Ⅲ）。
- 札は紋章盤ではノードに対する%で盤面と一緒に拡大縮小し、最小14px（門は12px）を保つ。縦の分岐図では固定サイズ（門はノード名と重ならないよう左側）。
- 読み上げ：ノードの `aria-label` に「二択Ⅱ（相手: 豪腕）、どちらか1つ」や「ここから二択Ⅱに分かれる」を加える。
- 「視差効果を減らす」設定では相方の輪の脈動を止める。

## 3. 詳細の比較表示

- 二択のノードを選ぶと、詳細は **2つを左右に並べた比較表示** になる（データの並び順で固定。見ている方を金の太枠）。
- 各列：スキル名／方向（紋章盤のみ）・必要SP・必要Lv（2以上の時）・状態（選択済み・封印）／効果（説明文から「（4bと選択）」などの注記を除く）。
- 見出し：「二択Ⅰ」の札と「どちらか1つだけ習得できる」。選んだ後は「『猛攻の構え』を選択済み（選び直しはリセット）」。
- もう一方の列をタップすると、その詳細に切り替わり、盤面の選択と強調も移る。
- せんしの詳細では、二択の時だけ上の事実欄を「前提」だけにする（SP・Lv・相手は比較表示にある）。背の低い画面（高さ700px以下）では上の見出し行を省き、習得ボタンを画面内に残す。

## 4. 習得の確定（2回押し）

- 二択で選べる時のボタン：「『猛攻の構え』を選ぶ」／小さく「SP2・『不動の構え』は封印」。
- 1回目：確認待ち（`treeSwapConfirm = "choice:<ノードID>"`）。ボタンが橙色の「本当に選ぶ？」／「『不動の構え』は封印・戻すにはリセット」に変わる。習得しない。
- 2回目：既存の誤タップ防止（`armConfirm`／`confirmReady`）を通ってから、既存の `acquireNode` を呼ぶ。
- 確認中に別のノードやタブを触ると確認は解除される（既存のリセット・交換の確認と同じ扱い）。
- 選ばなかった側のボタン：「封印中」／「『猛攻の構え』を選択済み」（押せない）。
- 二択でないノードは従来どおり1回で習得する。

## 5. 実装の場所

- `js/ui/detail-tree.js`
  - 共通：`treeChoiceInfo`（組・番号・門・状態）、`createTreeChoiceTag`、`createTreeChoiceGate`、`treeChoiceAriaText`、`buildTreeChoiceCompare`、`treeChoiceButtonText`、`treeAcquireWithChoiceConfirm`。
  - 紋章盤（`buildWarriorWebGraph`）と縦の分岐図（`buildTreeGraph`）に印・門・線の状態・相方の強調を追加。
  - せんしの詳細（`buildWarriorCrestDetail`）と通常の詳細（`buildTreeNodeDetail`）に比較表示と2回押しを追加。
- `css/style.css`：全ツリー共通の「二択」節と、紋章盤用の数行。
- キャッシュ番号：`style.css?v=78`、`detail-tree.js?v=13`。

## 6. 検証

- 自動テスト `tests/skill-choice-ui.test.js`：全13ツリーで組と門を取り出せる、紋章盤の印・門・相方・切れ目、比較表示と切替、2回押し（誤タップ防止の待ち時間中は習得しない）、汎用と他職の縦の分岐図。既存の `warrior-web-tree-ui` も更新。
- 実画面（Playwright／iPhone SE・13・14 Pro Max 相当、タッチ操作）：印6つと門3つ、相方の強調、比較の切替、1回目は習得しない、他を触ると確認解除、2回目でSP消費、選んだ後の札と途切れた線、選ばなかった側は押せない、汎用ツリーの印と比較表示、習得ボタンが画面内。
- 未検証：実機の iPhone Safari。
