> 基本設計: [ダンジョン・ボス設計](dungeon-boss-design.md) / [3F・5F試験](dungeon-live-pilot-test.md) / [途中再開RV](reviews/dungeon-checkpoint-review-20261016.md)

## 設計上の決定

- **盗賊Lv5で「解錠術」を自動習得**。忍者は盗賊を熟練してから転職する上位職なのでLv1から使用可能。
- 解錠術は**探索専用の常時有効スキル**。通常戦闘アビリティやサブアビリティ枠、MP消費、アクティブスキルON/OFFには追加しない。既存スキルツリーのSP総量を変更しない。
- 鍵付き宝箱を発見すると**自動的に1回だけ**判定する。操作/YES・NO/ログタップ要求は一切ない。
- **初期成功率45%**。同じチームに盗賊・忍者が複数いても、対象メンバーの最も高い成功率を使用して**宝箱1個につき1回だけ**抽選する。人数による多重試行はしない。
- スキル未習得・全員戦闘不能・モンスター・他ジョブは解錠不可。操作を止めず、その場で宝箱を諦めて進行。
- 成功時のみ装備1個を`pendingDrops`へ追加。**中ボスを含め途中では確定しない。最終ボス撃破による完全踏破のみ持ち帰り、全滅・撤退・timeoutではUR/LR含む全未確定品をロスト**。
- 通常／自動／オフラインの抽選は共通の`dungeonTrial.rollPilotEvent`を使用。オフラインでは現在の戦闘シミュレーションで**生存しているパーティ**を判定して技能を利用。
- 宝箱の試行前には「解錠術の有無」だけを確認する。装備OP・ジョブ変更は戦闘中にできないため、その周回内の能動操作は不要。
- 3F・5F以外の35ダンジョンへの一括適用は保留。ゲームバランス校正後、10F・15Fへ展開。

### 今回採用しなかった案

- 既存の盗賊固有スキルツリーに新ノードを追加してSP総量を増やすこと（Lv99到達時のSP不足リスク）。今回の探索スキルは**ジョブレベルによる自動習得**。
- 課金アイテムで解錠100%にしたり、開封した宝箱を踏破前に所持確定させること。現時点では設計しない。
- レアモンスター・ボスのレアリティ天井を変更すること。鍵付き宝箱も最終的には装備経済全体で調整する。
