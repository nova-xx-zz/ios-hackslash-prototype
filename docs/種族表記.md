# 種族表記

## 2026-10-28：プレイヤー用種族の漢字表記統一

仲間作成の種族選択では、既存のカタカナ・ひらがな表示を漢字に統一する。名前は `js/data.js` の `RACES[id].name` を正本とし、仲間作成／プレビュー／編成／キャラクター詳細は同じ表示名を参照する。

| 内部ID | 旧表記 | 変更後 |
|---|---|---|
| `human` | ヒトゾク | 人族 |
| `beastkin` | ハーフビースト | 半獣人 |
| `sylvan` | もりびと | 森人 |
| `stonekin` | いわびと | 岩人 |
| `nocturne` | よあるきぞく | 夜行族 |
| `artisan` | こうじん | 工人 |
| `spiritkin` | せいれいぞく | 精霊族 |
| `giant` | きょじん | 巨人 |

仲間作成のラベル「しゅぞく」も「種族」に変更する。種族ID、能力補正`mult`、特性`passive`、経験値補正、説明文、既存キャラクターの保存形式は変更しない。新しい漢字表示は既存キャラクターにも自動適用される。

モンスターの固有名詞（例：スライム族、ゴブリン族）は対象外。種族選択モーダルの大規模なレイアウト改修は案①「コンパクト図鑑型」、案②「一覧・比較型」、案③「紋章・契約型」からデザイン選定後に実施する。今回は文字表記のみ修正する。
