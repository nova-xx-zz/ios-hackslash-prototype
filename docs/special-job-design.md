# 特殊ジョブ設計書（巡礼剣士）

> 作成日: 2026-10-08。**状態: 設計（プロトタイプでのテスト用に実装する）**。
> 位置づけは [課金設計書](monetization-design.md) §4.5（特殊ジョブ「巡礼剣士」（仮））。本書はその具体化で、技・数値・解放・画面・バランスの基準を決める。
> スキルツリーの共通の決まり（SPの配分・段・名前の付け方）は [スキルツリー設計書](skill-tree-design.md) に従う。数値の正本は実装後の `js/data.js`。

## 1. 目的と範囲

- 課金設計書§4.5の特殊ジョブを、**プロトタイプでテストプレイできる形**で入れる。
- 本番の販売（決済・解放根拠の台帳・購入の取り消し）は対象外。プロトタイプの解放は「無料の条件」と「テストショップ（無料で受け取れる）」の2つで代わりにする（§6）。
- 本番化するかどうかは、テストプレイの結果と課金設計書§5（経済・バランスの検証）で決める。

### 1.1 課金設計書§4.5から引き継ぐ制約

| 制約 | 本書での扱い |
|---|---|
| 通常難度の得意な周回先で単独運用できる。高難度は編成の工夫が必要 | 「ひとり旅の加護」（§4）で、1人のときだけ強くなる。推奨Lvより十分高いレベルで、得意なダンジョンを1人で周回できる強さに合わせる（§8） |
| 同条件の物理専門職を全場面で上回らない | パーティの中では、せんしと同じくらい、けんごう・しにがみより弱い（§8.2） |
| 吸収攻撃は与ダメージ依存・MP消費あり・最大HPを超えない | 吸収の技はMPを使う。吸収は今の戦闘の仕組みのまま（最大HPを超えない） |
| 全体回復・蘇生・味方支援を同時に充実させない | 回復は自分だけ（祈りの灯）。味方全体の回復・蘇生・味方への強化は持たない |
| 苦手: 多数敵・物理が通りにくい相手・長期のMP不足 | 全体攻撃は1つだけでMPを使い、単体より弱い。攻撃はすべて物理（属性なし）。MPは少なめ |
| スキルツリーは固有1本＋汎用3枠、通常と同じSP・レベル上限 | 固有ツリー「巡礼の誓約」（56SP）＋汎用3枠。Lv99まで |
| ソロでも敵数・抽選・報酬は通常どおり。EXPを合算しない | 変えない（今もEXPは生き残った1人ずつに同じ量。1人旅で1人あたりのEXPは増えない） |
| 1人で4チームを同時運用できるようにしない | 変えない（同じキャラは1チームにしか入れない） |
| 既存の吸収職（あんこくし・しにがみ）を置き換えない | 吸収は技の効果が中心で、パッシブの吸収はあんこくしの半分。闇属性も持たない |

## 2. ジョブの基本

| 項目 | 内容 |
|---|---|
| ID | `pilgrim` |
| 名前 | じゅんれいけんし（巡礼剣士）。コマンド名「じゅんれい」 |
| 区分 | 特殊職（`tier: "special"`）。基本職・上級職とは別の欄に並べる |
| 説明 | 各地の聖地を巡る旅の剣士。仲間がいなくても戦い抜く術を身につけており、ひとりのときに真価を発揮する |
| 転職 | 人間のキャラだけ。解放（§6）されていれば、どのキャラもいつでも転職できる。ほかのジョブと同じく **Lv1から** |
| 系統タグ | `pilgrim`（固有ツリーは巡礼剣士だけのもの） |

### 2.1 能力値（Lv1の基礎値）

| ジョブ | HP | MP | ATK | MAG | DEF | SPD |
|---|---|---|---|---|---|---|
| せんし（基本） | 34 | 4 | 11 | 2 | 8 | 6 |
| あんこくし（基本） | 30 | 10 | 12 | 6 | 7 | 6 |
| けんごう（上級） | 42 | 4 | 15 | 2 | 9 | 8 |
| しにがみ（上級） | 36 | 14 | 17 | 9 | 8 | 8 |
| **じゅんれいけんし** | **40** | **12** | **13** | **6** | **10** | **7** |

- 上級職並みの合計だが、攻撃（ATK）はけんごう・しにがみより低く、守り（HP・DEF）に寄せる。
- MAGは祈りの灯（自分の回復）のため少しだけ持つ。

### 2.2 装備できる種類

| 枠 | 種類 |
|---|---|
| 武器 | 剣・槍 |
| 盾 | 小盾・大盾 |
| 頭 | かぶと・ずきん |
| 体 | よろい・軽よろい |
| 二刀流 | なし |

剣と盾の旅の剣士。両手の大剣・刀は持たない（攻撃に寄りすぎないため）。

## 3. 技（ジョブの技）

| Lv | 技 | 消費MP | 内容 |
|---|---|---|---|
| 1 | 旅路の一閃 | 0 | 敵1体に物理攻撃（威力1.2） |
| 5 | 糧断ち | 4 | 敵1体に物理攻撃（威力1.3）。与ダメージの5割を吸収 |
| 10 | 守りの誓い | 6 | 自分のDEFを15秒間1.5倍にする |
| 15 | 巡礼の薙ぎ | 8 | 敵全体に物理攻撃（威力0.85） |

- 全体攻撃は「巡礼の薙ぎ」だけで、MPを使う。MPが尽きると単体攻撃だけになる（長期戦・多数敵が苦手）。
- 守りの誓いは自分だけ。効果の間は掛け直さない（今の強化の仕組みのまま）。

## 4. ひとり旅の加護（ジョブの特性）

| 条件 | 効果 |
|---|---|
| そのチームの編成が**巡礼剣士1人だけ**のとき | ATK+30%、受けるダメージ−40% |

- 2人以上のチームでは効果がない（パーティの中で強くなりすぎないため）。
- 能力値の画面に「ひとり旅の加護（1人のとき ATK+30%・被ダメージ−40%）」と出し、効いているときは「発動中」と表示する。
- ATK+30%は、装備のセット効果・スキルツリーの割合ボーナスと同じ段で足して掛ける。受けるダメージは種族・ツリー・装備の被ダメージ倍率に掛ける。
- オフライン精算でも同じように効く（チームの人数で判定するため）。

## 6. 解放（プロトタイプ）

| 方法 | 条件 | 内容 |
|---|---|---|
| 無料 | **深淵の心臓（ノーマル）を踏破**する | 本番のジョブクエストの代わり（クエストの仕組みはまだないため） |
| テストショップ | **業火の霊峰（ノーマル）を踏破**すると受け取れる | 商品「特殊ジョブ『巡礼剣士』早期解放」（仮価格980円。テスト中は無料） |

- 解放は**アカウント単位**（解放すると、すべての人間のキャラが転職できる）。
- どちらか一方を満たせば解放（無料と購入の根拠は別々に持ち、どちらかがあればよい＝課金設計書§4.5の OR 判定）。
- 無料の条件を満たした後は、ショップの商品は「解放済み」になり受け取れない。
- 受け取り・解放をしても、能力値や技は同じ（購入による上乗せはない）。

## 8. バランスの基準と計測（案の段階）

計測は `tools/lib/sim.js` に案を差し込んで行った（人間・適正装備・素直なスキル振り。ノーマル）。数値は実装後に計り直して本書を更新する。

### 8.1 1人旅（ひとり旅の加護あり）

キャラのLvを「ダンジョンの推奨Lv＋0／＋10／＋20」にしたときの踏破率（%）。比べるのは同じ条件で1人だけで挑んだ場合。

| ダンジョン（推奨Lv） | じゅんれいけんし | あんこくし | しにがみ | けんごう |
|---|---|---|---|---|
| ささやきの森（4） | 0 / 100 / 100 | 0 / 0 / 20 | 0 / 40 / 100 | 0 / 97 / 100 |
| 蜃気楼の砂丘（17） | 0 / 0 / 40 | 0 / 0 / 0 | 0 / 0 / 0 | 0 / 42 / 100 |
| 灼熱の大神殿（30） | 0 / 8 / 95 | 0 / 0 / 0 | 0 / 0 / 0 | 80 / 100 / 100 |
| 雪原の砦跡（41） | 0 / 0 / 3 | 0 / 0 / 0 | 0 / 0 / 0 | 95 / 100 / 100 |
| 炎の鍛冶場跡（53） | 0 / 3 / 57 | 0 / 0 / 0 | 0 / 0 / 0 | 95 / 100 / 100 |
| 幽霊船（65） | 0 / 0 / 35 | 0 / 0 / 0 | 0 / 0 / 12 | 100 / 100 / 100 |
| 雲上の道（77） | 13 / 88 / 90 | 0 / 0 / 35 | 0 / 0 / 62 | 100 / 100 / 100 |
| 天空宮殿（88） | 20 / 73 / 83 | 0 / 47 / 40 | 5 / 100 / 97 | 100 / 100 / 100 |
| 堕ちた城塞（98） | 75 / 85 / 85 | 0 / 0 / 0 | 0 / 0 / 0 | 100 / 100 / 100 |

- 基準: **推奨Lvではほぼ1人で踏破できず、推奨Lv＋20で、得意なダンジョン（敵の特性が合う所）なら1人で周回できる**。雪原の砦跡のように苦手（堅牢・物理が効きにくい敵）なダンジョンは＋20でも難しい。
- 終盤（推奨Lv90以上）はキャラのLvが99で頭打ちになるため、＋10・＋20の差が出ない。

### 8.2 パーティの中（ひとり旅の加護なし）

初期パーティの「せんし2人目」を入れ替えたときの、推奨Lvの踏破率（%）。ノーマルは適正装備だけ、ハードは推奨Lv＋10・スキルツリーあり。

| ダンジョン | せんし | あんこくし | けんごう | しにがみ | じゅんれいけんし |
|---|---|---|---|---|---|
| ノーマル（9か所の平均の目安） | 58〜80 | 38〜78 | 95〜100 | 60〜93 | 50〜88 |
| ハード（同） | 25〜78 | 12〜87 | 50〜100 | 28〜98 | 27〜80 |

- じゅんれいけんしは、せんしと同じくらいで、けんごう・しにがみより弱い。「物理専門職を全場面で上回らない」を満たす。

### 8.3 既存の課題（本書の範囲外）

計測の中で、**けんごうは1人でも全ダンジョンを推奨Lvでほぼ100%踏破できる**ことが分かった。消費MP0の全体攻撃（旋刃嵐、威力0.95）を毎ターン使えるためで、パーティでもほかの職より大きく強い。巡礼剣士の「1人で周回できる」価値は、けんごうと比べると目立たない。けんごうの調整は別に行う（§10）。

## 9. 本番との違い（プロトタイプでやらないこと）

- 決済・購入の取り消し（返金）と、その後の扱い（課金設計書§4.5の停止・保管・復帰）
- ジョブクエスト（無料解放は深淵の心臓の踏破で代わりにする）
- 解放根拠のサーバー台帳（プロトタイプでは端末のセーブの購入記録と踏破記録から判定する）

## 11. 確認すること（テスト）

- 解放: 無料条件・ショップのどちらでも転職できる。両方満たさないと転職できない。無料条件の後はショップで受け取れない。
- ひとり旅の加護: 1人のときだけ能力値・被ダメージが変わる。2人以上では変わらない。オフライン精算でも同じ。
- スキルツリー: 56SPで全部取れる。どのLvでも「開いているマスの必要SP ≧ 持っているSP」。
- 1人旅とパーティの踏破率が§8の基準に入る。
