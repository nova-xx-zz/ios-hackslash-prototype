# 一次職全編成攻略・ダンジョン／スキル設計の基本原則

> **方針策定: 2026-10-18 / 状態: ゲームデザインの設計原則（達成・実装済みとは判定しない）**
> 対象: Web→iOS共通のゲームコア。一次職=基本6職、二次職=対応する上級6職。
> 本書は今後の設計・セルフRVで優先する仕様判断の「軸」。数値目標・新しい対抗手段は仮説であり、コードや確率をまだ変更していない。
> 既存の現在値: [スキルツリー設計](skill-tree-design.md) / [要件定義](requirements.md) / [モンスター設計](monster-design.md) / [本番化・課金](production-plan.md)。
> 現在の3/5階層・特性持ち抽選は試験ブランチの設計／測定で、通常版main・正式版には未反映。

## 1. 動かさない方針（プロダクトの柱）

**「一次職は攻略の自由、二次職は攻略効率。勝敗を決めるのは職業の格ではなく、育成とビルドの工夫」**

1. **一次職5人だけで本編35ダンジョンすべてに勝ち筋を用意する。** 全員同じ職業も含み、特定の一次職を必須にしない。基本6職から重複可で5人選ぶ職構成は**252通り**（順序の違いを除く `C(10,5)`）。理想は各難易度でも攻略可能性を維持するが、Normalを最優先ゲートとし、Hard/Extraは対抗手段の実装・実戦闘検証後に順次受け入れる。
2. **「勝ち筋がある」と「同じ準備で同じ勝率」は区別する。** 5人僧侶、5人魔法使い等の偏った編成では、装備・スキル/優先度・OP・強化や到達Lvの要求が上がってよい。全編成で同じ手軽さや周回効率は保証しない。
3. **二次職は専門性・時間短縮・安定性という価値。** 同等の装備予算、育成到達度、スキル設定であれば、主に**ゲーム内の攻略所要秒・失敗率・周回効率**が改善するように調整する。速度10〜25%短縮は**仮の検証目標**で、全組合せへ一律保証する数値ではない。やり込んだ一次職が準備不足の二次職を上回るのは歓迎する。
4. **二次職・特殊職・UR/LR装備・有償商品を「必須鍵」にしない。** 無課金で入手・育成できる複数の合法ビルドで道を開く。強力な装備／課金は手間や攻略時間を軽くできても、不可能を可能へ変える唯一の手段にはしない。
5. **「何が足りないのか」を調べて改良できる。** 敗因を属性/物理魔法耐性・持久力・火力・命中/弱体・HP/MP・制限時間から読み解けるログや図鑑の情報設計が必要。回答を1つに固定しない。
6. **長いダンジョンの全滅で未確定ドロップを全ロストするルールは維持。** だから最低条件と見通しは明示し、理不尽な対策不能パック／課金でしか回避できない壁を作らない。自動周回中に操作を要求するQTEやYES/NOは追加しない。

## 2. 最低限の準備条件（「何も考えず全編成で勝てる」わけではない）

「最低条件」は**特定職必須／特定商品の所有**ではなく、ダンジョンの前に獲得可能な攻略準備のこと。最終的な数値はダンジョン別に測定する。

| 観点 | プレイヤーに要求してよいこと | 要求してはいけないこと |
|---|---|---|
| レベル | 推奨Lvを基準に、特に偏った編成は追加育成が必要。プレイヤーのLv上限99を超える要件は作らない（最終ダンジョン表記Lv100と整合を取る） | 全員同じ職に変えること、上限超えLv |
| 装備 | 前に解放済みのダンジョンで取れる装備レベル・部位・レア度、現実的な強化を選ぶ | 次の未踏破ダンジョンの固有品・UR/LR・+99を前提にする |
| スキル | 習得済みの固有/汎用ツリーから必要な効果を選び、ON/OFF・優先度・分岐を調整する | 必須ジョブだけが使える専用スキル1個を唯一の突破口にする |
| OP・強化 | 弱点対策、攻撃、回復、MP維持などを組み合わせて編成の不足を補う。強化で攻撃/耐久を伸ばす | 全員に理論最高値OPを要求、入手経路のない対抗OPを要求 |
| 入手経路 | 少なくとも1つの有効な対抗手段を、そのダンジョンの**前**に無料・再現性ある方法で得られるようにする | Normal踏破にそのHard/Extra専用ドロップを必須とする循環依存 |
| 情報・AI | 属性・特性・敗因がわかり、フルオートAIが設定した戦術を実行する | 出撃中の手動選択/瞬間操作がないと勝てない仕組み |

- **最低条件（Gate A）**: 推奨レベル帯に到達し、前の解放済み地域の現実的な装備を揃え、1つ以上の攻め手＋持久手段を持つ。通常編成のNormal攻略を想定。具体的な強化値は `DUNGEONS[].benchmarkGear` と実際のドロップ/強化石経済を測って定める。
- **工夫条件（Gate B）**: 必要な敵への対策を1系統以上組み込み、ツリーとAI優先度を調整する。偏り編成や深層/Hardへの挑戦を想定。
- **やり込み条件（Gate C）**: OP・装備セット・強化・分岐・サブアビリティの組合せを詰める。Extraや高効率周回に価値を置く。**サブアビリティの他ジョブ育成は選択肢であり、一次職だけで攻略できる保証を崩す必須条件にはしない。**

上のA/B/Cはプレイヤーへの理不尽な必須ステップではなく**テスト用育成予算のレベル**。特定の入手経路・強化値・OP確率は今後の検証で決める。

## 3. 戦闘の対策は必ず複数ルートを持たせる

**ダンジョンの必須対策ごとに「一次職固有の得意技」＋「全一次職が利用できる代替策」を作る。** ただし代替策には装備枠、OP枠、SP、攻撃速度、MP、ダメージ量などのトレードオフを持たせ、職の個性を消さない。

| 敵・詰み方 | 得意な職/スキルの例（現行仕様） | 全職に開く必要がある代替策（設計候補） |
|---|---|---|
| 霊体: Extraで物理0倍 | 魔法使いの魔法、僧侶の魔法 | **魔法ダメージ種別そのもの**を出せる共通武器/アクセサリー効果・汎用技 |
| 魔法耐性: Extraで魔法0倍 | 戦士・盗賊・武闘家の物理 | **物理ダメージ種別そのもの**を出せる共通攻撃/武器機能 |
| アンデッド: Extraで聖以外0倍 | 僧侶の光の矢/聖なる加護、武闘家の聖属性技 | 全職が選択できる**聖属性の攻撃手段**、属性付与などの入手しやすい経路 |
| 堅牢: DEF大幅増 | 戦士/盗賊の防御ダウン、武闘家の防御無視 | 防御無視/魔法/防御ダウンを一部取り込める装備OPや汎用技 |
| 長丁場でHP/MP枯渇 | 僧侶の回復、吸収型の武闘家/暗黒使い | HP吸収・回復・被ダメ軽減・MP効率・敵弱体の複数の育成経路 |
| 300秒超え・火力不足 | アタッカーの攻撃系統 | 役割の偏ったPTでも火力を底上げできる強化・OP・AI優先設定 |

**重要**: 属性（炎/氷/聖など）とダメージ**種別**（物理/魔法）は別の判定軸。例えば「物理攻撃に聖属性を付ける」だけでは、霊体の**物理0倍**を突破できない。新しいOPや共通技で物理/魔法の別ルートを作る場合、`battle.js` の実際の判定とオートAIまで一体として設計する。

**現状とのギャップ**: 現行では敵特性がExtraで0倍になる一方、全職が自由にダメージ種別と聖属性を獲得できる共通手段は未整備。したがって「252構成すべてのExtra攻略可能」は**まだ未達・未検証**。追加の対抗手段を実装するまでは、1戦に対策不能な敵が揃う配置や完全無効の出現を制御することも検討する。

## 4. 一次職ごとの強みと「1職5人」の極端な編成

| 一次職 | 強み（維持する役割） | 5人重複編成でも確保すべき逃げ道 |
|---|---|---|
| 戦士 | 前衛耐久・防御ダウン・安定した物理 | 魔法種別の対霊体、聖属性、長期回復 |
| 魔法使い | 属性・範囲・魔力支援 | 魔法耐性対策の物理攻撃、防具/HP・MP維持 |
| 僧侶 | 回復・聖属性・支援 | 火力/制限時間対策の攻撃装備・攻撃OP・攻撃優先度 |
| 盗賊 | 手数・速度・解錠・弱体 | 耐久/持続回復・霊体対策・ボス火力 |
| 武闘家 | 防御無視・吸収・物理突破力 | 魔法種別・属性の別解、過剰な一強化の回避 |
| 暗黒使い | 吸収・攻撃ダウン・闇属性 | 聖属性・霊体/魔法耐性の相性穴・MP管理 |

- **不得意は不可能ではなく、準備コスト・戦闘時間・装備選びの差として表す**。
- 特定職だけがほぼ100%踏破できる一方、標準編成が半分程度のときは、先にPT差・敵特性・強化の実効値・装備OPの入手性を検証する。直ちに強い職をナーフする判断はしない。
- 一次職Lv99の「一次職の極み」は将来の**追加やり込み要素**であり、全本編踏破の必須条件にはしない。二次職への転職はLv50で可能なままにする。

## 5. ダンジョン設計テンプレート（新規・改修時に埋める）

各ダンジョンを追加/改修する時は、敵倍率だけでなく以下を文書とテストに持つ。

| 項目 | 記録する内容 |
|---|---|
| 進行 | 地方/ID、階層3・5・10・15、推奨Lv、敵数1〜5、最低通常戦闘数、ボス位置、イベント |
| 最低育成 | 到達時の実測で獲得できる装備レベル・レア度/平均強化値、想定スキルLv、必要な対抗手段の入手経路 |
| 戦術 | 想定敵特性/属性、弱点のヒント、物理・魔法・聖属性・貫通等への**少なくとも2つの攻略ルート** |
| 消耗 | HP/MP消費、時間制限300秒、序盤から深層への耐久要求、失敗時全ロストと獲得期待値 |
| ビルド差 | 汎用編成、各職5人の6極端編成、回復なし/魔法なし/物理なし等の構成を実戦闘で測定 |
| ボス | ギミック・予告・フェーズ・取り巻き・通常敵との対抗手段の重複/完全詰みの有無 |
| 結果 | 同seedのクリア率・ゲーム内秒・敗北階層/原因・強化石/装備・対策スキル発動・全滅ドロップ0 |
| 状態 | 数字は実測か仮説か、試験専用か通常版に採用済みか、RV/CIリンク |

出撃中にYES/NOを求めたり、泉を自動で飲ませたりして操作を強制しない既存方針を守る。

## 6. 数値の受入基準（**暫定・実装前の検証案**）

以下は合格済みの測定結果ではなく、**「ビルドの工夫が機能しているか」を判断するための物差し**。

| 対象 | 暫定的な合格の考え方 |
|---|---|
| 本編Normal 35件 × 一次職252構成 | すべてに**再現できる合法ビルドで攻略可能性**がある。想定混成PTは適正装備+スキルで踏破率70〜90%を目安。偏りPTは適切なOP/強化の追加投資で**50%以上**を探索目標とする（実測により変更可）。 |
| Hard | 一次職だけでも勝ち筋を残す。Normalより必要な装備/スキル設定を引き上げてよいが、未入手アイテム必須・構成固定・理不尽な完全詰みは禁止。各構成の数値閾値は実戦闘検証後に確定。 |
| Extra | 対策の必要性を最大化してよいが、**特定職不在という理由だけの永久詰みは禁止**。全職向け物理/魔法/聖の代替対策が存在・入手可能なことを前提に、252構成の実戦闘検証を段階的に進める。 |
| 二次職の利点 | 同じ装備予算・同等の育成条件・同じダンジョン・固定seedで、典型的な二次職PTの**ゲーム内攻略時間10〜25%短縮（仮説）**を評価。勝率だけで評価しない。 |
| 経済とリスク | 同じ上限で全滅時の未確定アイテムを常にロスト。準備可能な戦術なら、過度な周回ロストを強いる1択状態を検出する。 |

検証範囲は5人PT（ジョブのみ252パターン。8種族・装備全組み合わせではない）から開始。テスト実施は以下の順序。

1. **初期パーティ＋6種の全員同職＋回復役なし/攻撃偏重等の代表PT**で3F/5Fの実戦闘を検証（通常敵/ボス・Normalから）。
2. 代表PTで3/5/10/15F、ダンジョン35件、Normal/Hard/Extraを増やす。特性種別/階層/対策不可数・攻略時間・報酬ロストを観測する。
3. 未クリアや異常な時間が出たダンジョンに対して**敵の再編成・汎用対抗手段・OP・スキル設計**を改善。単に敵ステータス一律低下/強職の一律ナーフで調整しない。
4. **252構成 × ダンジョン35件 × 3モード**（合計26,460組の構成×ダンジョン×モード）を独立した複数seedで網羅的に監査。組合せが膨大なので毎PRの必須CIは代表シナリオ、全探索は別のバッチ/定期品質ゲートに分ける。
5. 二次職編成を一次職と比較し、クリア率・ゲーム内秒・強化石/装備の実収支と、無課金経路を検証する。

既存の `tools/simulate.js` の推奨Lv基準や旧4PT基準だけでは「252編成の勝ち筋」は証明できない。旧測定表は**当時の測定結果**として残し、将来の測定と混同しない。

## 7. 今わかっていること（設計と実装のギャップ）

- 2026-10-18の試験ブランチでは、洞窟5Fの初期PTが約54〜57%、武闘家を含む一部のPTが100%（いずれも各100周）。上記の「同程度の育成で職を固定しなくても戦える」設計が**未達**の可能性がある。測定数と乱数差に注意する。
- 特性1〜3体のランダム配置・元特性4体以上の上限制御は試験段階。10/15Fは一部ダンジョンの**敵生成抽選だけ**を試しており、実際の難易度・プレイ秒数はまだ検証していない。
- `TRAIT_STRENGTH.extra` の0倍は、「代替ダメージ種別／聖属性を全一次職に供給」という設計と現状で矛盾する可能性がある。対策が実際に配布されていることを確認せずに難易度だけ強化しない。
- 物理攻撃で魔法耐性を突破する、魔法攻撃で霊体を突破する等の基本相性は実装済み。一方、全職の**汎用のダメージ種別切替、聖属性付与OP/共通技**は案の段階であり、価格・出現率・UI・セーブ方式の改修も未実施。
- 二次職との攻略時間比較、252構成の成否は未測定。**「設計したから達成した」とは表示しない**。

## 8. 今後のゲームデザイン作業順序

**優先1:** 霊体・魔法耐性・アンデッド・堅牢への非課金・全職共通の代替対抗手段を定義し、入手時期・OP/汎用ツリーの枠コストを決める。一次職固有の強みは優位性として残す。

**優先2:** 3F/5Fで代表PTの実戦闘シミュレーション。スキルON/OFF・優先度・武器OP・強化で**勝率と所要時間に意味のある差**が生まれることを測る。

**優先3:** 10/15F・ボスの階層構成、MP持久戦、全滅ロスト・報酬と戦闘数を調整。特に5人同職で対処不能な敵の同時出現を監査する。

**優先4:** 一次職／二次職の性能差を実測して、二次職の時短・安定性が価値となるよう調整する。現時点でジョブ数値の一律変更は行わない。

**優先5:** UIに敵特性/対策ヒント/全滅要因を伝え、無操作自動周回の流れを維持したまま考察できるようにする。
