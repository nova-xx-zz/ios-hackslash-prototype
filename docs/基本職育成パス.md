# 基本職育成パス（プロトタイプ検証）

## 目的
基本職の育成時間を短縮し、パーティ編成・装備・OP・スキルビルドの検証に集中できるようにする。

## 対象・購入
- 対象リポジトリ: `ios-hackslash-prototype`（正式版への移植は別判断）
- 商品ID: `basic_job_max_pass` / 解放キー: `basicJobMaxPass`
- アカウント共通の買い切り権利を `state.purchases.unlocks` に保存する。
- 表示価格は仮の980円。**プロトタイプでは決済を行わず、既存ショップのテスト無料購入を使用する。**
- 権利の購入だけでは既存のキャラクターやジョブレベルを変更しない。

## 適用操作
1. ショップで「基本職育成パス」を無料テスト購入。
2. 仲間の詳細 →「ジョブ」タブ → 育成対象の基本職を選択。
3. 確認ダイアログ後、選択した基本職のレベルだけをLv.99（`CHAR_MAX_LEVEL` 上限）にする。
4. 現在のジョブに適用した場合はキャラの現在Lv/EXP/HP/MPを整合させ、他ジョブの場合は`jobLevels[jobId]` のみ更新する。
5. 進行は購入権利と共に既存セーブへ保存し、失敗時はその適用をロールバックする。

## 適用しないもの
- 上級職・特殊職・モンスター、未購入時の育成。
- 探索中のパーティ所属キャラクター。
- スキルツリーの構造、取得済みノード、覚醒段階、覚醒条件（**別途設計する**）。
- 他の基本職のレベル、装備、所持品、編成状態。
- 上級職の解放条件そのもの（既存の基本職Lv.50条件は変更しない）。

## 検証観点
- 購入前不可、購入後は一度だけ購入可、セーブ/ロードで権利保持。
- 現職/未経験基本職それぞれに適用、EXPの上限、転職復元、既存ツリー進行保持。
- 探索中・モンスター・上級職/特殊職・ロスター外拒否。
- プロトタイプのテスト購入権利はユーザー端末のセーブ由来。本番の正規権利としては信用せず、移植時にサーバー検証が必要。
