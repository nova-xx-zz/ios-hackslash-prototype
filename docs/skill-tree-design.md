## 1. 全体像

| 項目 | 内容 |
|---|---|
| 持つツリー | 1キャラ（人間のみ）が「固有ツリー1本＋汎用ツリー3枠」の計4本を同時に持つ。モンスターはツリーを持たない（個体値・合成で育てる） |
| 固有ツリー | ジョブの系統（6系統）ごとに1本。基本職と上級職は同じツリー（例: せんし・けんごう → 剛勇の心得） |
| 汎用ツリー | 3枠。枠ごとに決まった2種から1つを選ぶ（いつでも交換でき、交換した枠のSPだけ戻る） |
| SP | ジョブのレベル−1。4本で共有する。ジョブごとに別に持つ（転職すると、そのジョブのレベルとツリーに切り替わる） |
| マス（ノード） | パッシブ（能力値・会心率などが上がる）とアクティブ（技を覚える。固有ツリーのみ）。前提のマスと、二択（同じグループはどちらか一方） |

## 2. 現行の問題（2026-10-07）

| | 必要SP | マス数 | 技 |
|---|---:|---:|---:|
| 固有ツリー（1本） | 14 | 7（二択1組を含む） | 1 |
| 汎用ツリー（1本） | 3 | 3（二択1組を含む） | 0 |
| **合計（固有＋汎用3枠）** | **23** | | |

- SPはLv99で98あるのに、全部取るのに23しかかからない。**Lv24で取り終わり、残り75SPは使い道がない**。ダンジョンはLv100まで（7地方）あるのに、ツリーはLv20台で成長が止まる
- 効果が固定値（ATK+3など）だけなので、Lv100前後（ATK 150〜190）では数%にしかならない
- ジョブの技も Lv15 で全部覚え終わる（各ジョブ4つ）。Lv15以降に増える技がない

## 3. 拡張の方針（案）

1. **Lv99で全部埋まる**: 4本の合計必要SPを **98（＝Lv99のSP）** にする。固有ツリー56＋汎用ツリー14×3枠
2. **レベルで開く段**: マスに「必要なジョブのレベル」（`reqLevel`）を付け、Lv20〜90の段を順に開ける（固有はLv20から10ごと、汎用はLv25・45・65）。SPが余っていても、先の段は取れない。全部取り終えるのはLv99
3. **後半は割合の効果**: 新しいマスはATK+5%のような割合（`statPct`）にして、レベルが上がっても効き目が薄れないようにする（SPDだけは成長しないため固定値のまま）
4. **技を増やす**: 固有ツリーの技を1つ→4つ（Lv1・30・60・90）。Lv90の「奥義」はそのジョブで最も強い技にする
5. **二択を増やす**: 固有ツリーの二択を1組→3組（Lv1・40・70）。同じジョブでも育て方が分かれるようにする
6. **今のマスはそのまま残す**: 既存のマス（ID・必要SP・前提）は変えない。セーブの移行は不要で、すでに振ったSPもそのまま。Lv24以上のキャラは、更新するとすぐに振れるSPが増える

| Lv45 | — | 4 |

## 4. 仕組みの変更（実装の範囲）

| 変更 | 内容 |
|---|---|
| マスの必要レベル `reqLevel` | ジョブのレベルが足りないマスは取れない（`canAcquireNode` で判定）。図では鍵の印と「Lv○で解放」を出す |
| 割合の効果 `statPct` | `{ type: "statPct", stat: "atk", value: 0.05 }`。固定値の加算のあと、セット効果などの割合ボーナスと同じ段で掛ける（`computeStats`） |
| ツリーの図 | 段が増えるので縦に長くし、左に段のLvを表示してスクロールで見る |
| 振り直し | 今は固有ツリーの二択を選び直せない。マスが増え二択も3組になるので、**「このジョブのツリーを振り直す」**（4本ぶんを全部戻す）を追加する。費用は強化石（使ったSP×20個。Lv99で全部振っていても約2,000個＝周回数分）。探索中・自動周回中のチームは不可 |
| シミュレーター | `tools/lib/sim.js` の「素直な振り方」に `reqLevel` と `statPct` を入れる |
| 難易度の再調整 | ツリーが強くなる分、推奨Lv20以上のダンジョンの敵の強さ（`DUNGEONS[].power`・`modePower`）を `node tools/simulate.js --calibrate` で合わせ直し、`--check` と `tests/difficulty.test.js` を通す。目標の踏破率（推奨Lvで○%）は変えない |
| お知らせ | テストプレイヤー向けに「スキルツリーの拡張」と「SPが増えて振れるようになった」ことを告知する |

セーブの形は変えない（マスのIDごとの取得ランク `exclusiveRanks`・`general[枠].ranks` のまま）。新しいマスは未取得として始まる。

### 5.1 名前の付け方

技・マスの名前は、ほかのゲーム（ドラゴンクエスト・ファイナルファンタジー・ポケモンなど）や漫画の固有の技名と同じものや、それを連想させる造語を使わない。一般的な言葉（「ヒール」「ドレイン」「体当たり」「絶対零度」など）はよいが、作品で作られた言葉（「ブリザド」「アルテマ」「ギガスラッシュ」など）や、作品の技名とまったく同じ表記は避ける。プレイヤーの技（ジョブ・スキルツリー）は漢字の名前にし、ジョブごとにテーマをそろえる（魔法は「紋章」の力＝炎紋弾・雷紋陣、剣は「閃」、拳は「拳・掌」、闇は「黒・魂」など）。テイムしたモンスターの技は、ひらがなの説明的な名前のままにする。
