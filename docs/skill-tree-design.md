## 1. 全体像

| 項目 | 内容 |
|---|---|
| 持つツリー | 1キャラ（人間のみ）が「固有ツリー1本＋汎用ツリー3枠」の計4本を同時に持つ。モンスターはツリーを持たない（個体値・合成で育てる） |
| 固有ツリー | ジョブの系統（6系統＋特殊職の巡礼剣士）ごとに1本。巡礼剣士の「巡礼の誓約」は [特殊ジョブ設計書](special-job-design.md)§5。基本職と上級職は同じツリー（例: せんし・けんごう → 剛勇の心得）。進行はジョブごとに別（上級職はLv1からSPを貯め直す） |
| 汎用ツリー | 3枠。枠ごとに決まった2種から1つを選ぶ（いつでも交換でき、交換した枠のSPだけ戻る） |
| SP | ジョブのレベル−1。4本で共有する。**全部取るとちょうど98（Lv99のSP）** |
| マス（ノード） | パッシブ（能力値・会心率などが上がる）とアクティブ（技を覚える。固有ツリーのみ）。前提のマス・二択（同じグループはどちらか一方）・**段（必要なジョブのレベル）** |
| 振り直し | 4本ぶんを全部戻す。費用は強化石（使ったSP×20個。全部振っていても1,960個）。探索中・自動周回中のチームは不可 |

### 1.1 拡張の経緯（2026-10-07）

拡張前は、全部取るのに必要なSPが23（固有14＋汎用3×3）で、**Lv24で取り終わり、Lv99までの75SPに使い道がなかった**。効果も固定値（ATK+3など）だけで、Lv100前後（ATK 150〜190）では数%にしかならなかった。拡張では次のようにした。

1. **Lv99でちょうど全部埋まる**（固有56＋汎用14×3枠＝98）
2. **段ごとにレベルで開く**（固有はLv20から10ごと、汎用はLv25・45・65）。SPが余っていても先の段は取れない
3. **後半のマスは割合の効果**（`statPct`。ATK+5%など）。SPDだけは成長しないので固定値
4. **固有ツリーの技を1つ→4つ**（Lv1・20・50・90）。Lv20・50の技は、敵の特性への対策（防御ダウン・聖属性・強化など）にした
5. **二択を1組→3組**（Lv1・40・70）
6. **今のマスはそのまま残す**（ID・必要SP・前提は変えない）。セーブの移行は不要で、すでに振ったSPもそのまま

## 5. 戦闘の仕組み（敵の特性・属性・強化と弱体）

ツリーの技が生きるように、戦闘エンジン（`js/core/battle.js`）に次を加えた。

| 仕組み | 内容 |
|---|---|
| 敵の特性 | **アンデッド**（聖属性以外が効きにくい。聖属性が弱点）・**霊体**（物理が効きにくい）・**魔法耐性**（魔法が効きにくい）・**堅牢**（防御がとても高い）。強さはモードで変わる（下の表）。どの敵が何を持つかは [モンスター設計書](monster-design.md)§3.5 |
| 属性 | 技の属性は炎・氷・雷・聖・闇（無ければ無属性）。敵の属性ごとに弱点1.5倍・耐性0.5倍（火→氷が弱点・炎に強い、氷→炎が弱点、水→雷が弱点・炎に強い、風→雷が弱点、土→雷に強い、闇→聖が弱点・闇に強い、光→闇が弱点・聖に強い） |
| 弱体 | 当たった敵の防御・攻撃・素早さを一定時間下げる（鎧砕き・弱点暴き＝防御、呪縛・闇の帳＝攻撃、足止めの刃＝素早さ）。同じ能力には強い方が残り、時間が延びる |
| 強化 | 味方全体の攻撃・魔力・防御を一定時間上げる（鬨の声・魔力の紋・金剛の陣） |
| 聖属性付与 | 聖なる加護: 15秒間、味方全体の無属性の攻撃が聖属性になる（物理の味方もアンデッドを攻撃できる） |
| 防御無視 | 敵の防御の一部を無視する（徹し＝全攻撃25%、剛勇覇斬＝30%。上限80%） |
| AI | 技ごとに「今使った時の見込み効果」を比べる方式はそのまま。効かない攻撃は0と見積もり、弱体・強化は「効いている間に増える味方の与ダメージ（または減る被ダメージ）」を見積もって比べる。掛かっている間は掛け直さない（強化を「優先」にしていても、全員に掛かっている間は他の技を使う）。回復の見積もりも魔力アップを反映する |
| 速さ | AIの見積もりで能力値を何度も使うため、1つの戦闘の中では各キャラの能力値・パッシブを1回だけ計算して使い回す（戦闘中は変わらない）。オフライン精算も含め、拡張前より速い |

| 特性の強さ | ノーマル | ハード | エクストラ |
|---|---|---|---|
| 効きにくい攻撃（アンデッドへの聖属性以外・霊体への物理・魔法耐性への魔法） | 0.6倍 | 0.3倍 | **効かない（0）** |
| 堅牢な敵の防御 | 1.5倍 | 2.5倍 | 4倍 |

## 6. モードと難易度の基準

| モード | 考え方 | 合わせ方（`tools/lib/difficulty.js`） |
|---|---|---|
| ノーマル | 武器と強化だけ（スキルツリーなし）でも最悪何とかなる。ツリーを振れば安定する | 推奨Lvで、適正装備だけの踏破率が70%になる強さ（`DUNGEONS[].power`）。確認: 適正装備＋スキルで85%以上、適正装備だけで50〜90% |
| ハード | 適正装備＋スキルで安定。一部はノーマルと同じく装備だけでも行ける | 推奨Lvで、初期パーティ（適正装備＋素直なスキル振り）の踏破率が88%になる強さ（`modePower.hard`） |
| エクストラ | 敵の特性が最大。スキルとパーティ編成を合わせないと踏破できない | 4つのパーティ構成（バランス・聖属性重視・魔法重視・物理重視）のうち、一番合ったもので88%になる強さ（`modePower.extra`）。合わない構成では大きく下がる |

再調整の結果は §6.1。

### 7.1 名前の付け方

技・マスの名前は、ほかのゲーム（ドラゴンクエスト・ファイナルファンタジー・ポケモンなど）や漫画の固有の技名と同じものや、それを連想させる造語を使わない。一般的な言葉（「体当たり」「絶対零度」など）はよいが、作品で作られた言葉や、作品の技名とまったく同じ表記は避ける。プレイヤーの技（ジョブ・スキルツリー）は漢字の名前にし、ジョブごとにテーマをそろえる（魔法は「紋章」の力＝炎紋弾・雷紋陣、剣は「閃」、拳は「拳・掌」、闇は「黒・魂」など）。テイムしたモンスターの技は、ひらがなの説明的な名前のままにする。
