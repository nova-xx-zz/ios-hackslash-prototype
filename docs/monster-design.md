## 2. 敵の定義（`ENEMY_TEMPLATES` の1件）

```js
{
  key: "slime", name: "スライム",
  hp: 16, atk: 6, mag: 0, def: 2, spd: 4,   // 推奨Lv1・1戦目での基礎値（§3で伸ばす）
  exp: 6,                                    // 倒した時のEXPの基礎値
  color: "#4dc37a", icon: "🟢",              // 表示用（図鑑では画像を出さない）
  element: "水",                             // 属性。図鑑の表示用で、戦闘の計算には使わない
  tamable: true, tameChance: 0.35,           // テイムできるか・成功率（§5）
  desc: "どこにでもいる最弱の魔物。…",        // 図鑑の説明文
}
```

- 属性は 火・水・氷・風・土・光・闇・毒・無 の9種類（光34・闇44種が多い）。戦闘の相性は現行では無い（将来構想）
- 種族の能力値の個性は基礎値の比で表す（例: ゴーレム系はDEFが高くSPDが低い、コウモリ系はSPDが高い）

## 3. 敵の強さ

### 3.1 計算式（`buildEncounter` / `makeEnemy`）

```
mult  = (1 + (推奨Lv − 1) × 0.12) × (1 + 戦闘の番号 × 0.06)    // ENEMY_LEVEL_GROWTH・ENEMY_BATTLE_GROWTH（戦闘の番号は0から）
p     = mult × power × (レア敵なら 1.3)                         // power: ダンジョンごとの強さの倍率
HP・ATK・DEF = round(基礎値 × p)                                 // MAG・SPDは伸ばさない
EXP   = round(基礎値 × mult × (レア敵なら 5)) × モードのEXP倍率   // EXPには power を掛けない
数    = min(5, 3 + floor(推奨Lv / 5)) 体（通常の敵から無作為）
ボス戦（最後の戦闘）は、上の数に加えてボスを mult × 1.7（BOSS_MULT）で先頭に置く
```

- 1Lvあたりの伸び（12%）は味方の能力値の伸び（`js/core/stats.js`）とそろえ、推奨Lvで挑んだ時の手応えが奥のダンジョンでも変わらないようにしている
- `power` は難易度の基準（推奨Lvの想定プレイヤーで踏破率80〜95%、`tools/simulate.js --check`）に合わせて `--calibrate` で決める。EXPに掛けないのは、難易度の調整でレベル上げのペースが変わらないようにするため
- 奥のダンジョンほど `power` が小さいのは、敵の基礎値を地方ごとに大きく作っているため（1未満でも敵は十分強い）

### 3.2 敵の行動

- 敵は技を持たず、ATBゲージが溜まると生きている味方から無作為に1人を通常攻撃する（`performEnemyAction`）
- ダメージ: `max(1, round(ATK − 味方のDEF × 0.4))` × 乱数0.9〜1.15 × 味方の被ダメージ倍率
- 行動の速さはSPD（`SPD × ATB_RATE(7) × 経過秒`）。戦闘開始時のATBは0〜30の乱数

### 3.3 ボス・レア敵

| 種類 | 出方 | 強さ | 報酬 |
|---|---|---|---|
| ボス | 各ダンジョンの最後の戦闘に必ず1体。名前は「◯◯の主」 | 通常の敵の1.7倍 | 通常のドロップに加え、4%で名のある装備（`BOSS_UNIQUE_CHANCE`） |
| レア敵 | ボス戦以外の1戦闘ごとに4%（`RARE_ENCOUNTER_CHANCE`）で、敵1体がレア敵に入れ替わる。名前に★ | HP・ATK・DEFが1.3倍 | EXP5倍。必ず追加で装備を1個落とす（25%で名のある装備、それ以外はSR以上） |

- レア敵は「ゴールドスライム」「宝箱ミミック」など、出会うと嬉しい見た目・名前にする。ボス・レア敵はテイムできない（テイムできるのは通常の敵だけ）
- 5戦のダンジョンでは1周あたり約15%でレア敵に出会う

### 3.4 モード（ハード・エクストラ）

- 同じダンジョン・同じ敵を、推奨Lv+10（ハード）・+25（エクストラ）として出す。`mult` はモード込みの推奨Lvで計算し、`power` は `DUNGEONS[].modePower`（`tools/simulate.js --calibrate-modes` で、そのLvの想定プレイヤーが踏破率88%、Lv100を超える分は1Lvごとに−2%）
- EXPはハード1.5倍・エクストラ2倍。落ちる装備にオプション効果が付く（[装備設計書](equipment-design.md)§7）
- 解放はハードがそのダンジョンのノーマル踏破、エクストラがハード踏破。テイムの対象と成功率はノーマルと同じ

## 5. テイム

### 5.1 テイムの抽選（`attemptTame`・`rewards.rollTame`）

- ダンジョンを**踏破した時だけ**、その周で倒したテイムできる敵の中から1体を無作為に選び、その種族の `tameChance` で成功を判定する（1周に最大1体）。全滅した周はテイムできない
- テイム率は序盤ほど高く（スライム35%）、奥の地方ほど低い（アビス地方8〜9%）
- 成功すると、どのダンジョン・モードでも**Lv1・経験値0**でロスターの控えに加わる（`addTamedMonster`）。テイムしたその戦闘のEXPはもらわない
- オフライン精算でも同じ抽選を使う

### 5.2 テイムしたモンスターの能力

| 項目 | 内容 |
|---|---|
| ジョブ | 人間のジョブには転職できず、種族専用のジョブ（`MONSTER_JOBS[種族]`）を持つ。技は3つで、Lv1・5・10で覚える |

### 5.4 モンスター合成（`js/model/inventory.js`）

```
素材1体のEXP = round((種族の基本EXP + 素材が積み上げたEXP × 0.5) × (合成先と同じ種族なら 1.5))
種族の基本EXP = expForLevel(その種族が出る一番早いダンジョンの推奨Lv)   // fusionBaseExp
```

- 素材にできるのは、合成先以外の、どのチームにも編成していない、お気に入りでないモンスター。すべて／種族ごとにまとめて選べる
- 素材は消え、装備していたアイテムは所持品に戻る。2回押しで確定し、すぐ保存する
- テイム直後のLv1でも基本EXPが入る。その地方の推奨Lvまで上げるのに必要な素材は、序盤で2〜4体、終盤で約20体（同族なら約2/3）

## 6. 追加・調整の手順

### 6.1 敵を追加する

1. `ENEMY_TEMPLATES` に1件足す（`key` は英小文字とアンダースコア。基礎値は同じ地方の敵と同じくらいの合計にする）
2. 出すダンジョンの `pool`（通常）・`boss`・`rares` に `key` を足す
3. `node --test` と `node tools/simulate.js --check` で難易度の基準を確かめる。外れたら `--calibrate` の提案で `power` を直す

### 6.2 テイムできる種族を追加する

1. 敵として `ENEMY_TEMPLATES` にあり、どこかのダンジョンに出ること
2. `TAME_SPECIES` に `[敵のkey, 型, テイム率, 種族の説明, 技の名前3つ]` を足す（`RACES`・`MONSTER_JOBS` は自動で作られる）
3. テイム率は同じ地方の種族に合わせる（序盤20〜35%、終盤8〜11%）
4. 合成の基本EXPは出てくる一番早いダンジョンで自動的に決まる

### 6.3 調整の目安

- 敵の強さはまず `power`（ダンジョン単位）で合わせ、個別の敵の基礎値は個性（硬い・速いなど）を出す時だけ変える
- テイム率を上げると合成の素材も増える（合成の育成ペースにも効く）
- モードの強さは `--calibrate-modes` の提案で `modePower` を直す
