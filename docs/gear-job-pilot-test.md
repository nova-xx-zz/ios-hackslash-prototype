# 3F/5F 装備×ジョブ相乗効果：実機試験モード

> 2026-10-16 / 試験対象: `?dungeonPilot=1&gearTrial=1` / 本番環境には未適用（2026-10-19更新：mainに統合済み。検証版で `?dungeonPilot=1&gearTrial=1` の両方を付けた時だけ動き、保存先は `qpgeartrial:` に分離）
>
> 既存の [装備×ジョブ診断](reviews/gear-job-synergy-20261016.md) の120周データに基づく**暫定の強化補正**。正式採用前の段階。

## この試験で判断すること

**装備強化とジョブ編成がそれぞれ意味を持ち、同時に活かすほど攻略が安定する**か。初期ジョブにも攻略の選択肢があり、固定の2僧侶編成だけを正解にしない。

### 試験用の強化値補正

- 従来: `Math.ceil(plus * rarityMultiplier * 0.08 * baseStat/primary)`。N+1とN+5の主能力が同じ+1に止まることがある。
- 今回の仮式: 従来の強化値に、**+4で主能力+1、+8で+2、+12で+3**を追加。+12以降は追加ボーナスを3に固定し、+99でも追加は最大3。
- 複数能力のある装備は主能力との比率に応じ、ほかの能力にも補正。アイテムごとの元データは変更せず、`itemStats`の計算時にのみ適用。
- SRの+50/+99でオプション穴解放する既存仕様、強化確率・費用、UR/LR継承天井・液体抽出・解錠術には変更なし。
- シミュレーターで使った仮式と、実機試験の`js/core/equipment.js`は**同じコア関数**を使用し、乖離を防ぐ。

### 洞窟5Fの難易度

- この専用モードだけ、洞窟4F/5Fの通常敵を20%弱体化する暫定案を**適用しない**（倍率1.0）。
- ボスの強さ・HP60%防御フェーズ・敵数・戦闘回数、ドロップは従来どおり。
- 他の3Fおよび洞窟の通常パイロットは、URLフラグなしの既存条件で稼働する。
- 元の敵強さと回復役2人で十分攻略できる可能性が高いため、敵弱体化PR #108のmainマージは保留。

## セーブとロスト

- 試験URLのみ`qpgeartrial:`プレフィックスを使う。`qpdungeonpilot:`と通常の`jobquest_save_v1`は読み込まない・更新しない。別のURLでは別のセーブから始まる。
- 試験ではFirebase同期を無効化。本番channelにある時は`dungeonPilot`も`gearTrial`も無効化する。
- 進行中runの戦闘計画・HP・乱数・未確定ドロップは、前段のダンジョンチェックポイントで保存。
- **最終踏破以外で報酬を確定しない。全滅・撤退・時間切れではUR/LR含む全未確定品をロスト**。強化・OPが有効でもこのルールを変えない。

## 4観点セルフRV（独立エージェントではなく同一AI）

1. **ゲーム性:** 装備強化なしでもジョブ編成で道が開け、編成が弱い場合は装備+4の補助が体感できる試験。僧侶2人を強制しないよう他ジョブも比較する必要あり。
2. **計算・互換:** 現行`itemStats`はURLフラグなしで不変。追加ボーナスは+4/8/12で区切り、+99まで最大3。全レア度テストで下限と単調増加を検証する。
3. **不正・保存:** セーブ別プレフィックス、クラウド無効。クライアントローカル保存の改ざん耐性は未解決、本番サーバー検証が必要。
4. **QA・運用:** CIのゲームテスト・Webビルド、Safari/Chrome手動を要求。R〜LRと+99でのバランス、OP穴開け、石供給を正式採用前に再校正。

**判定:** 3F/5Fの機能ゲート試作として利用可。正式ゲームの強化式、強化費用、本番難易度の確定ではない。
