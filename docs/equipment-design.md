# 装備設計書

> 更新日: 2026-10-07。現行実装の参照基点: `34fee54` 以降（PR #45）。
> 装備（武器・盾・頭・体・装飾品）の種類・シリーズ・ジョブの装備制限・セット効果・ドロップ・レア度・強化・名のある装備・オプション効果をまとめる。データの形と計算順は [詳細設計書](detailed-design.md)§1.2・§2.1・§2.2・§2.10、強化石の経済は [本番化・課金方針](production-plan.md)§5 を参照。
> 数値の正本は `js/data.js`（`ITEM_TYPES`・`ITEM_SERIES`・`JOB_EQUIP`・`RARITIES`・`ENHANCE_CONFIG`）、`js/uniques.js`（名のある装備）、`js/options.js`（オプション効果）。

## 1. 全体像

| 項目 | 内容 |
|---|---|
| 装備枠 | 右手（`main`）・左手（`off`）・頭（`head`）・体（`body`）・装飾品①〜③（`acc1`〜`acc3`）の7枠 |
| 部位 | 武器・盾・頭・体・装飾品の5種類 |
| ふつうの装備 | 種類26 × シリーズ8 ＝ 208種（`ITEM_BASES`）。名前は「シリーズ名＋種類のカナ」（例: アイアンソード） |
| 名のある装備 | 203種（7地方 × 29種。うち呪われた装備21種）。少し強く、固有の特殊効果と1行の説明文を持つ |
| レア度 | N／R／SR／UR／LR。名前の色で表す（白・水色・緑・紫・金） |
| 強化 | +0〜+99。強化石を使い、失敗しても消費する。天井あり |
| オプション効果 | ハード・エクストラで落ちた装備にだけ1〜3個付く |

能力値の大きさは主に**装備のレベル**（拾ったダンジョンの推奨Lv）と**レア度**と**強化値**で決まる。シリーズは能力値を変えず、セット効果と落ちる地方を表す。

### 2.3 おまかせ装備

ジョブの基礎値から作った重み（HP÷30・MP÷20・ATK÷10・MAG÷10・DEF÷8・SPD÷7）で装備の価値を測り（`itemScore`）、枠ごとに一番良い物を選ぶ。右手は「両手武器1本」と「片手武器＋左手」の合計を比べる。**呪われた装備は選ばない**（自分で付ける）。

## 3. シリーズとセット効果（`ITEM_SERIES`）

ふつうの装備は、拾ったダンジョンの推奨Lv（ハード・エクストラでも元の推奨Lv）に応じたシリーズで落ちる（`seriesForLevel`）。同じシリーズを2・4・6個付けるとセット効果が段階的に付く。左右の手に同じシリーズの武器を持つ場合も枠ごとに数える。

| シリーズ | 落ちるダンジョン（推奨Lv） | 2個 | 4個 | 6個 |
|---|---|---|---|---|
| ブロンズ | Lv1〜10 | HP+4% | DEF+4% | ATK+4%・MAG+4% |
| アイアン | Lv11〜16 | DEF+5% | HP+6% | 被ダメージ-5% |
| スチール | Lv17〜31 | ATK+5% | DEF+5% | 会心率+5% |
| シルバー | Lv32〜46 | MAG+5% | MP+10% | 回復量+10% |
| ミスリル | Lv47〜61 | SPD+5% | ATK+5%・MAG+5% | 消費MP-10% |
| ドラゴン | Lv62〜76 | HP+6% | ATK+6% | 与ダメージの5%を吸収 |
| ホーリー | Lv77〜89 | DEF+6% | MAG+6% | 被ダメージ-8% |
| アビス | Lv90〜100 | ATK+6%・MAG+6% | SPD+6% | 会心率+6%・吸収+4% |
- 割合の効果は、装備・スキルツリーまで足した能力値に掛ける（詳細設計§2.1）。会心率などはセット効果・名のある装備・オプション効果の合計を種族・スキルツリーの値と合わせて戦闘に使う
- 6個そろえるには7枠のうち6枠を同じシリーズにする必要があり、「強いけれどシリーズが違う装備」との選択になる
- シリーズの切り替わりは地方の切り替わりとほぼ同じ（ヴェルデ地方は前半ブロンズ・後半アイアン）

## 4. 能力値

### 4.1 拾った時の能力値（`rewards.createItem`）

```
装備のレベルの倍率 = 1 + (装備のレベル − 1) × 0.12        // ITEM_LEVEL_GROWTH（キャラの能力値の伸びと同じ）
能力値 = max(1, round(重み × レア度倍率 × 装備のレベルの倍率))
```

- 装備のレベル＝拾ったダンジョンの推奨Lv（ハード・エクストラは+10・+25したLv）。奥のダンジョンほど装備も強くなり、集め直す意味が続く
- 例: Lv100のダンジョンで拾ったSRの剣は ATK `round(3 × 2.0 × 12.88)` ＝ 77、DEF 13

### 4.2 レア度（`RARITIES`）

| レア度 | 色 | 能力値の倍率 | 出る割合 | 分解で得る強化石 |
|---|---|---:|---:|---:|
| N（ノーマル） | 白 `#f2f2f2` | 1.0 | 71% | 5 |
| R（レア） | 水色 `#5ccbff` | 1.4 | 22% | 20 |
| SR（スーパーレア） | 緑 `#5fd480` | 2.0 | 6.5% | 80 |
| UR（ウルトラレア） | 紫 `#b97dff` | 2.8 | 0.35% | 350 |
| LR（レジェンドレア） | 金 `#f2c14e` | 4.0 | 0.15% | 1,500 |

- 名前にレア度の文字は付けず、名前の色で表す（表示時は常に `rarityColor(key)` から引く）
- レア敵が落とす装備と名のある装備はSR以上から抽選する（重みの比でSR約93%・UR約5%・LR約2%）

### 4.3 強化（+0〜+99）

```
成功率 = max(下限, 基本成功率 × 減衰^現在の+値)
1回の強化石 = 基本の費用 + 現在の+値 × 費用の増え方
強化値のボーナス = ceil(+値 × レア度倍率 × 0.08 × その能力値の重み ÷ 主能力値の重み)
```

| レア度 | 基本成功率 | 減衰 | 1回の強化石（+0） | 費用の増え方 | 下限 |
|---|---:|---:|---:|---:|---:|
| N | 90% | 0.995 | 3 | 0 | 3% |
| R | 75% | 0.990 | 8 | 0 | 3% |
| SR | 55% | 0.985 | 20 | 0 | 3% |
| UR | 35% | 0.978 | 60 | 0 | 3% |
| LR | 15% | 0.965 | 150 | 350÷98（+98で500） | 0.5% |

- 失敗しても強化石は消費し、+値は下がらない
- **天井**（`enhancePity`、ON）: 今の+値で失敗に使った強化石が、その段の期待消費（費用÷成功率）の1.5倍に達したら、次の強化は必ず成功する。LR +0→+99は天井なしの期待消費約249万個に対し、天井ありで中央値約195万個（`node tools/economy.js`）
- **確定強化石**（`guaranteedStone`、OFF・課金用）: 必要個数 `max(1, ceil(その段の期待消費 ÷ 10,000))` で必ず+1。LR +0→+99は合計303個
- 手動・自動の分解では、レア度ごとの強化石を得る（強化値・天井は引き継がない）

## 5. ドロップ

### 5.1 1周で落ちる数

| 入手のしかた | 数 |
|---|---|
| 戦闘に勝つ | 1個＋40%で追加1個（`REWARD_RULES.extraDropChance`） |
| 道中の宝箱 | 戦闘の間に60%でイベント → 40%で宝箱 → 65%で1個 |
| レア敵 | 倒すと必ず1個（25%で名のある装備、それ以外はSR以上） |
| ボス | 4%で名のある装備を1個 |
| ふつうのドロップ | 0.3%で、その地方の名のある装備に変わる |

ドロップは**踏破した時だけ確定**し、全滅した周は持ち帰れない。自動分解の対象レア度は出撃時の設定で振り分ける（名のある装備とロックした装備は、レア度が合っても所持品に残す）。5戦のダンジョンでは1周あたり約8個（N・R・SRを分解すると強化石約115〜120個）。

### 5.2 部位と種類の決め方（`rollItemDrop`）

1. 部位を重みで選ぶ: 武器22・盾10・頭15・体15・装飾品38（`ITEM_DROP_SLOT_WEIGHTS`。装飾品は1人3枠まで付けるので多め、盾は持てるジョブが少ないので少なめ）
2. その部位の種類から等確率で選ぶ（シリーズはダンジョンの推奨Lvで決まる）
3. レア度を重みで選ぶ（§4.2）
4. ハード・エクストラならオプション効果を付ける（§7）

## 6. 名のある装備（`js/uniques.js`）

厨二病・ダークファンタジーの雰囲気の固有装備。地方ごとに、26種類の装備の種類を1つずつ＋呪われた装備3つの29種、7地方で203種。

| 項目 | 内容 |
|---|---|
| 能力値 | 同じ種類のふつうの装備の1.2倍（`UNIQUE_STAT_MULT`）。呪われた装備は1.45倍（`CURSED_STAT_MULT`） |
| 特殊効果 | 1つ。奥の地方（tier 1〜7）ほど大きい（下表） |
| シリーズ | 持たない（セット効果の数に入らない） |
| レア度 | SR以上 |
| 入手 | その地方のダンジョンで、レア敵の追加ドロップの25%・ボスの4%・ふつうのドロップの0.3% |
| 表示 | 名前（例: 黒き木刀《漆黒丸》）と1行の説明文 |

特殊効果（`UNIQUE_EFFECTS`。値は tier 1 → tier 7）:

| 効果 | 値 | 効果 | 値 |
|---|---|---|---|
| 会心率 | +3% → +9% | ATK／MAG／DEF／SPD | +4% → +10% |
| 吸収 | 2% → 8% | HP／MP | +5% → +14% |
| 回復量 | +5% → +17% | 被ダメージ | −3% → −9% |
| 消費MP | −5% → −14% | | |

**呪われた装備**（地方ごとに3つ）は、大きな恩恵（ATK／MAG／DEF／SPD +15%→+33%、会心率+8%→+17%、吸収6%→15%）と、呪い（被ダメージ+10%→+16%、最大HP−12%→−18%、SPD−15%→−21%、消費MP+15%→+21%）を1つずつ持つ。例: 血啜りの魔剣「ATK+15%／呪い: 被ダメージ+10%」。おまかせ装備では選ばない。

## 7. オプション効果（`js/options.js`）

ハード・エクストラで落ちた装備（名のある装備を含む）にだけ付く。同じ効果は重ならない。

| モード | 個数 | 強さ |
|---|---|---|
| ハード | 1〜2個（半々） | ある程度強い |
| エクストラ | 2〜3個（半々） | かなり強い |

| 効果 | 種類 | ハード | エクストラ |
|---|---|---|---|
| ATK／MAG／DEF＋固定値 | 固定値 | 重み1.5 × 装備のレベルの倍率 × 1〜2 | 同 × 2.5〜4 |
| SPD＋固定値 | 固定値 | 重み1 × 同 × 1〜2 | 同 × 2.5〜4 |
| HP＋固定値／MP＋固定値 | 固定値 | 重み5／4 × 同 × 1〜2 | 同 × 2.5〜4 |
| ATK／MAG／DEF／SPD／HP／MP＋% | 割合 | +3〜6% | +7〜12% |
| 会心率 | 戦闘 | +2〜4% | +5〜8% |
| 吸収 | 戦闘 | 2〜3% | 4〜6% |
| 回復量 | 戦闘 | +5〜10% | +12〜20% |
| 被ダメージ | 戦闘 | −2〜4% | −5〜8% |
| 消費MP | 戦闘 | −4〜8% | −10〜15% |
| パーティの獲得EXP | 周回 | +5〜10% | +12〜20% |
| パーティの強化石 | 周回 | +5〜10% | +12〜20% |

- 割合は1%刻み。固定値は装備のレベルで伸びる（少なくとも1）
- 「パーティの獲得EXP」「パーティの強化石」は、その装備を付けたキャラがいるチームの獲得量を増やす（同じチーム内で合計）
- 表示は「ATK+23」「会心率+3%」「被ダメージ−4%」の形

## 8. 旧セーブの移行

- 旧形式の装備枠 `{ weapon, armor, accessory }` は `main`・`body`・`acc1` に移す
- 旧形式の8種類の装備（剣・杖・かぎ爪・よろい・ローブ・お守り・指輪・くつ。能力値1つ）は、ブロンズの同じ種類に移し、能力値・レア度・強化値・天井ゲージを引き継ぐ（名前は新しい種類の名前にする）
- 図鑑（アイテム辞典）の「手に入れた」記録も新しい種類のkeyに移す

## 9. 追加・調整の手順

- **種類を足す**: `ITEM_TYPES` に1件足すと、8シリーズぶんの `ITEM_BASES` が自動で増える。持てるジョブを `JOB_EQUIP`（モンスターなら `MONSTER_EQUIP`）に足し、名のある装備を地方ごとに1つずつ `UNIQUE_DEFS` に足す
- **シリーズを足す**: `ITEM_SERIES` に `minLevel` とセット効果を足す（`minLevel` の順に並べる）
- **名のある装備を足す**: `UNIQUE_DEFS[地方]` に `[key, 名前, 種類, 効果, 説明文]` を足す（呪いは効果を `"恩恵>呪い"` と書く）
- **強さを変えた時**: 想定プレイヤーの適正装備（`DUNGEONS[].benchmarkGear`）で難易度の基準を確かめる（`node tools/simulate.js --check`、`node tools/progression.js`）。強化石の量を変えた時は `node tools/economy.js` で到達期間を確かめる
