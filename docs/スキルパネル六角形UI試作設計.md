- **共通ビュー**: 全職の固有スキル正本は7系統とも17ノード、汎用は各6ノード3枠で共通。専用SVG6種類、分岐チップの切り抜き防止、色・フィルター・SP・リセット・スキル詳細・汎用交換UIを戦士と同じコンポーネントに統一する。
- **職業別初期スキル**: 戦士は従来の「剣撃突き」を維持。他職では現在習得できるアクティブ技（見つからなければ習得済みノードまたは最初のノード）を選択する。前のキャラのフィルター・選択ノードを持ち越さない。
- **既存正本**: 職ごとの getExclusiveTree / getTreeState を使用し、習得条件・前提・二択・SP消費・汎用交換・転職後の個別進行・セーブ形式は一切変更しない。表示切替は保存しない。
- **覚醒**: Ⅰ〜Ⅲは全ジョブ共通の「準備中」の装飾で、クリック不可。今後実装するジョブ固有試練の予約領域とし、課金育成パスとも独立。現段階では覚醒用フィールドは保存しない。

## 2026-11-02 分岐チップの見切れ・杖の再調整
- **原因**: 六角形ノードのボタン全体に設定したCSS `clip-path` が、ノード上に重ねた二択グループ番号の円形チップまで切り取っていた。
- **修正**: ボタン自体の `clip-path` を解除し、背景用の `::before` に六角形の切り抜きを移す。内側のアイコン面は別途六角形で切り抜き、外に出たチップは正常に表示する。
- 分岐ノードに `choice-node` を付与して隣接ノードより高い重なり順に配置。チップは14px、上1px・右1pxに固定。タップできるのは従来どおりノード全体。
- **杖**: 斜めの柄と菱形＋多量の光エフェクトが剣・鍵に見えるため、魔法球を抱えた三日月状の飾り・直立した柄・石突の3要素に変更。小サイズのPNGプレビューで可読性を比較。
- **不変**: 六角枠寸法・アイコン表示比率70%・腕など他5種のSVG・色分け・SP・前提条件・習得処理・二択排他・セーブ・覚醒予約は変更しない。
- **検証**: CSSのクリップ対象・重なり順、分岐チップのDOMとタップ動作、杖SVGの構造、全件自動テスト・Webビルド。実際のiPhone Safariで最終的な見た目を再確認する。



## 2026-11-02 腕・杖アイコンの判読性改善
- iPhone実画面で、腕が曲がった管状に、杖が棒と丸に見えてしまう問題を確認。
- 腕のSVGは「握り拳」「力こぶ」の二つのシルエットに分割し、筋肉の輪郭と拳の陰影線を追加。ステータス上昇の既存分類（ATK・会心＝腕）は維持。
- 杖のSVGは丸い先端を菱形の魔法石に置き換え、長い柄と十字の光を描画。魔法・回復・MP・MAGなどの既存分類は維持。
- 六角パネルサイズ・アイコンの表示率70%・他の4分類のSVG・スキルデータ・習得処理・保存処理・覚醒予約には変更を加えない。
- SVGの拳・力こぶ・魔法石・光の形をテストで検証。最終的な判別性はiPhone Web実画面で再確認する。

## 2026-11-02 アイコンと六角枠のサイズ比を微調整
- iPhoneの全体表示で、専用SVGを76%まで拡大すると六角枠内が窮屈に見えるため、**アイコンのみ70%**に縮小（約2pxの差）。六角形の枠寸法・列数・タップ領域・ズーム・フィルター・習得ロジックは変更しない。
- 枠を2px拡張すると隣接六角の重なりが増えるため、まずアイコン縮小を採用。実画面で余白と認識性を再確認する。

## 2026-11-02 統合盤アイコン表示の視認性改善
- iPhoneの実画面で「アイコンが潰れて見える」と報告。調査したところ、6分類の効果→SVG割当は実装されていたが、六角マス内のSVGは59%（約20〜25px）と小さく、複雑な線画もあり、小サイズで形を識別しづらかった。
- 統合盤のみに6分類専用SVG（剣・体・盾・足・腕・杖）を追加。32×32の正方形viewBox、preserveAspectRatio=xMidYMid meetを固定。輪郭を簡略化し、塗りシルエットと太めの線画を併用。既存の紋章盤／詳細のSVGは変更しない。
- SVG表示領域は59%→76%。未解放時の不透明度は0.84→0.94、習得可能フィルターでの非該当パネルは0.28→0.48に調整。
- スクリーンショットの「習得可」フィルターが選択された場合、取得可能以外を暗くするのは意図した挙動。ただし形が消えるのは可読性に問題があるため、明るさを改善。
- スキル効果／SP消費／二択／セーブ／覚醒予約UIには変更なし。iPhone実画面で縮小時・全体時・フィルター時の形状が判別できることを再確認する。
- 自動テストでは6種SVGの属性、35パネルへの適用、CSSサイズ・コントラスト、キャッシュ更新を検証。実機での最終見た目はWeb反映後に確認する。

## 2026-11-02 統合盤UI試作（剣士先行）
- 現状の「戦士固有 / 汎用Ⅰ / 汎用Ⅱ / 汎用Ⅲ」の4タブを**統合パネル表示時だけ**廃止し、単一のスクロール可能な盤面で4系統を同時表示する。
- セクション: 上部に覚醒Ⅰ〜Ⅲの予約帯、その下に汎用Ⅰ・汎用Ⅱ、中央に戦士固有、最下部に汎用Ⅲ。データ構造は4本のままで混在させない。
- 画面フィルター: 全体 / 固有 / 汎Ⅰ / 汎Ⅱ / 汎Ⅲ / 習得可。フィルターは表示範囲だけを切り替え、習得状態や盤面の保存形式は変えない。フィルター中も詳細カードに表示するスキルは現在の選択を維持する。
- アイコン: 物理アクティブ=剣、魔法/回復/魔力強化/属性付与アクティブ=杖。ステータスは HP/吸収=体、DEF/被ダメージ軽減=盾、SPD=足、ATK/会心=腕。MP/MAG/省MP/回復補助=杖。装備枠と吸収は暫定で体に分類。複合効果は主な分類を一つ選び、詳細欄に効果を全表示する。
- 六角形アイコンはオリジナルSVGで生成し、外部のゲーム画像やアイコン素材は使わない。
- 汎用の装備ツリーの交換は各セクション見出しから可能。従来の2回押し確認、SPのリセット処理、Lv制限、排他条件、セーブ、ゲームデータは保持。
- 覚醒Ⅰ〜Ⅲは**すべて未実装・表示のみ**の鍵であり、押しても反応しない。将来の職業固有試練や実績で解放する予定。まだセーブデータに awakeningTier を追加しない。課金の基本職Lv99化とも独立。
- 既存の紋章盤は「旧盤面」から戻せる。初期状態ではこれまでの表示に戻すための比較機能を維持し、ユーザーによるWeb版での評価後に既定化を判断。
- すべてをiPhone縦幅で常時タップ可能な大きさで収めるのは難しいため、全体では盤面内部スクロール、集中時は系統フィルターで拡大表示する設計。
- 非対象: その他のジョブへの展開、覚醒機能本体、システム上のスキル増減、マスターデータやセーブ形式の変更。
- 未検証: iPhone実機での段組み・タップサイズ・画面下ナビとの干渉。GitHub Actionsの自動テストとWebリリースビルドを確認してからWeb画面で視認性を評価する。



## 2026-11-02 実機Webスクリーンショットを受けた再設計
- **変更理由**: 初版17マスの散在配置・大きな漢字は参考画像の密集した六角形のライセンス盤と外観が大きく異なるため、盤面を作り直した。
- **盤面構成**: 上から5/6/7/8/7/6/5マスの合計44マスを、同一座標式で密着表示する。17マスに実スキルを割当。残り27マスは施錠アイコンのみで、偽のスキルや取得条件は作らない。
- **グラフィック**: 大きな漢字の略称を削除。スキルを表す既存SVGアイコンを中央に大きく置く。攻撃/支援/防御/装備の色味を使い分け、状態（習得済・習得可能・未解放・二択封印）は枠色・輝きで判別。
- **経路**: 実際の前提関係かつ近距離のものだけ光路を描く。見た目の六角マス隣接は解放条件ではない。
- **操作**: 右上に盤面を覆っていた切替UIを盤面の外の独立した行へ移動。下部詳細・SP・振り直し・ズーム・全体表示は既存どおり。
- **非対象**: スキルデータ・セーブ・計算処理・汎用Ⅰ〜Ⅲ・他職業・既存紋章盤は変更しない。
- **追加検証**: 44マスの座標重複ゼロ・17SVGアイコン・27装飾ロック非操作・巨大漢字の不存在・切替UI独立を自動検証。
- **残る確認**: GitHub ActionsでテストとWebビルドを実施後、Web実画面のスクリーンショットで密集具合、発光、iPhone小画面のタップ感を評価する。



## 目的・適用範囲
- FF12のライセンスボードにある「埋めていく達成感」と、DQ11の六角形パネルの一覧性を、ソードクレスト向けに試す。
- **プロトタイプ版のみ**の比較試作。初期表示は既存の紋章盤。
- 対象は **剣士（job: warrior）の固有ツリー「剛勇の心得」** のみ。汎用Ⅰ〜Ⅲ・剣豪・その他の職業は既存UIを維持。
- main への導入・正式版への移管は、実画面での確認後に改めて判断する。

## 画面・操作
- 既存の固有/汎用タブ、SP、振り直し、キャラ送り、下部詳細ドック、下部ナビは維持。
- 固有ツリーの盤面右上に「紋章盤 / 六角パネル」の切替を設置。既定は紋章盤。表示モードは一時的なUI状態で、セーブデータには追加しない。
- 六角パネルは既存17ノード＋装飾ロック27マスの7段44マスを密着配置。個々のアイコンは既存の剣士紋章SVGを再利用し、名前は選択後の下部詳細に表示。
- 状態色は習得済＝金、習得可能＝青、未解放＝灰、二択封印＝赤。選択中パネルと、その前提パネルを強調。
- 盤面全体を初期表示。既存の拡大・縮小・全体表示、iPhoneのピンチ・ドラッグ、マウスホイールを再利用。
- ノードをタップすると詳細を選択するだけで、誤タップによる即時習得はしない。習得は下部詳細の既存ボタンから行う。

## データ・ルール
- js/data.js の EXCLUSIVE_TREES.warrior が唯一の正本。ノードID、前提、排他グループ、効果、スキルポイント、必要Lv、保存形式は変更しない。
- 表示の位置と実際の習得条件は別物。**六角パネルが隣接しているだけでは解放されない**。判定は必ず canAcquireNode()、習得は既存の treeAcquireWithChoiceConfirm() → acquireNode() を使用する。
- 二択の組番号と封印判定は既存の treeChoiceInfo() に従う。
- 将来パネルが追加され、表示座標が未定義のノードがあれば欠落描画せず従来紋章盤にフォールバックする。

## 実装箇所
- js/ui/detail-tree.js: 紋章盤と六角パネルの切替と描画分岐。
- js/ui/skill-panel-board.js: 六角座標・パネルUIの組み立て（スキル習得ロジックは持たない）。
- css/skill-panel-board.css: 六角パネルだけのスコープ付き装飾。
- index.html: 読み込み順とキャッシュ番号。
- tests/warrior-skill-panel-board.test.js: 切替、17ノード、状態、非対象職、データ不変性。
