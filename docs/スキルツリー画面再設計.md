# スキルツリー画面再設計（参考画像準拠）

2026-10-26 / 対象: プロトタイプ版 `ios-hackslash-prototype` / **レビュー前・未マージ**

## 1. 目的
仲間詳細に埋め込まれた円盤（旧画面）を、参考画像2枚目に近い**独立したダークファンタジー全高画面**へ変更する。今回は剣士（せんし）の固有ツリーを対象とする。汎用Ⅰ〜Ⅲと他職の計算・習得仕様は変更しない。

## 2. 画面要素（上から）
1. 左上「戻る」＋ SWORD CREST ブランド、右ではなく下段にスキルツリー見出し、SP、リセット。
2. せんし／汎用Ⅰ／汎用Ⅱ／汎用Ⅲの4つの排他的なタブ。
3. 左上に剣紋章と職名・ツリー名、背景ギルドを透かして見せる円形の紋章盤。
4. 紋章盤の**外側へ固定した6方向の札**（基礎・猛攻・破砕・覇道・鉄壁・装備）。
5. 複雑な飾り線よりも実際の前提線を優先。17ノード・実前提線16本・4状態・形状ごとの区別は保持。
6. ノードを選ぶと盤面直下に専用詳細パネルと習得操作を常設。最初は剣撃突き。
7. ズームボタンを盤面に重ねず、「表示調整」を展開した時のみ出す。ピンチ・拡大時ドラッグ・再描画時の視点保持を継続。

## 3. 表示の変更
- `#app` の背景は**剣士スキルツリー画面だけ**既存の `icons/title-guild.jpg` に変更。半透明グラデーションを載せ、参考画像の石造アーチの空気感を活かす。
- 全高モードでは上部キャラページャー・下部5タブ・グローバルナビを非表示にし、戻る矢印で仲間詳細へ戻る。
- 紋章盤を正方形の描画ステージにし、方向札を独立レイヤーへ移す。ズームしても札は動かさない。
- ノード直径を盤面の約8.4%（奥義9.8%）に抑え、3リング間の余白を確保。中心の大剣を引き立てる。
- 実前提線の未取得時の光量、補助同心円と放射線のコントラストを抑える。覇気への長い依存線は外周経由として中心の混雑を回避。
- 習得ボタンは、全面金塗りから深緑＋金縁の参考画像風に変更。
- 状態の凡例はスクリーンリーダー向けに残し、画面の見栄えを優先して視覚的に非表示。ノードの名称・状態は `aria-label` で提供。

## 4. データ不変条件
以下は**変更しない**：`EXCLUSIVE_TREES.warrior`・ノードID・前提・排他・レベル制限・習得処理・必要SP・振り直し費用／確認・セーブ／復旧構造。他職と汎用Ⅰ〜Ⅲの既存のスキル処理も変更しない。

## 5. 検証
- 自動テスト：`tests/warrior-web-tree-ui.test.js` および `tests/warrior-crest-reference-ui.test.js`。
- レイアウト目視：iPhone SE相当 375×667、iPhone 390×844、Pro Max相当 430×932、タブレット／PC幅。全17ノード、6札、習得詳細が左右で欠けないか。
- 操作：ノードタップ→詳細変更→習得、SP反映、探索中の変更制限、汎用タブ交換、リセット2回確認、戻る。
- 操作：表示調整展開→縮小0.80／全体0.92／拡大2.50、ピンチ、ドラッグ、通常時縦スクロール。
- iOS Safari/Chrome：キャッシュ更新 `style.css?v=73` と `detail-tree.js?v=10`、安全領域、旧セーブ再読込。
- 比較：参考2枚目の「画面全体が主役」「盤面の外に枝札」「スキルカードと習得ボタンが下にある」「背景が暗く重厚」の4点。
