## 3. 座標系とズーム（最重要）

- 盤面は **正方形1枚の `.tree-web-scene`**。枠（`.tree-web-viewport`）の短辺に合わせた一辺 `side` を JS が計算し、枠の中央に置く。
- SVG（魔法陣・ルーン・前提線。`viewBox="0 0 100 100"`、`preserveAspectRatio="none"`）と HTML（紋章・ノード・方向札。`left/top` を%）は **同じ0〜100の盤面座標** を共有する。
- scene の `font-size` を `side/100 px` にして **1em＝盤面1単位**。方向札の文字・余白は em、ノードは scene に対する%。
- **transform は scene にだけ** 掛ける：`translate(x, y) scale(k)`（`transform-origin` は中心）。追従するもの：剣紋章・魔法陣・ルーン・ノード・前提線・6方向の札。
- 固定するもの：背景・キャラ送り・タイトル・SP・タブ・職業見出し・ズームボタン・詳細カード・習得ボタン（scene の外）。
- 倍率：等倍1.0で盤面全体（札まで）が枠に収まる。最小0.8・最大2.6。ボタンは ×1.25 ／ ÷1.25、「全体」で1.0・中央。
- 基準点：ボタンは枠の中心、ピンチは2本指の中点、PCのホイールはカーソル位置（その点の盤面が動かないよう x, y を補正）。
- パンの範囲：盤面が枠からはみ出す分だけ（`max(0, (side×k − 枠)/2)`）。枠より小さい時（等倍・縮小）は中央に固定。
- iPhone Safari：盤面の枠は `touch-action:none`、`gesturestart` を止めて画面全体のズームを防ぐ。1本指は拡大中のみ移動。8px以上動いた直後の click は捨て、ノードの誤選択を防ぐ。
- 拡大位置は再描画（ノード選択・習得）で保持し、セーブしない。キャラ送りで別の仲間になったら等倍に戻す。画面回転などで枠の大きさが変わったら `ResizeObserver` で合わせ直す。

## 4. 盤面のデザイン（2026-10-26 改訂: 習得は中から外へ）

ユーザー要望により、習得の流れを「外から中」から **「中から外」** に変更した（案A）。以前は基礎の3つが外周→中心へ並び、剣撃突きから各方向へ外へ広がる形だった。

- **基礎＝剣紋章を囲む中心の環**（半径13）：鍛えた腕（真上）→戦いの勘→剣撃突き（左）。前提の無い最初のスキルが盤面のいちばん内側にある。
- **外へ伸びる5方向**（角度）：猛攻（右上 -54°）・破砕（右下 18°）・覇道（下 90°）・鉄壁（左下 162°）・装備（左上 234°）。札「基礎」は真上に置き、点線で中心の環へつなぐ。
- 5方向のノードの環：半径22／31／40。各方向とも内側ほど前提に近く、外ほど後で解放される。覇道は剛力（破砕の中段）から入るため1つ外の環から始まる（鬨の声31・歴戦の体40）。
- **奥義 剛勇覇斬は外枠に掛かる最外周の封印**（角度68°・半径44.5）。親の剣の頂（破砕の外周）と覇道の間に置く。
- 前提線（実データの16本）の通り道：剣撃突きから4方向（猛攻・破砕・鉄壁・装備の極意）へは基礎の環のすぐ外の導線（半径17.5）を回って配る。方向をまたぐ線は環の間の導線（26.5／35.5）へ斜めに入って弧で回り込む。
- 保証すること（テスト）：**どの前提線も子は親と同じ環かより外側**、無関係なノードの中心から4.4単位以上離れる、線どうしの交差・重なりなし。
- 将来の覚醒Ⅰ〜Ⅲは、外周に環を足すか外枠を段階的に灯す形で追加できる（中から外の延長）。設計は別途。
- 線の色：習得済み＝枝の色で光る（魔力の流れ付き）、習得可能＝金、未解放＝枝の色を淡く、二択で封印＝赤錆の点線。
- ノードの色：習得済み＝枝の色の縁と光、習得可能＝金の縁と脈動、未解放＝鉄色、Lv不足＝封印石＋錠、二択封印＝赤錆＋鎖。選択中は金の点線リングが回る。形：パッシブ＝円／アクティブ＝菱形／装備＝六角／奥義＝八芒星。
- 大きさ：剣紋章は盤面の15%、ノードは8.6%（見た目は約7%）、奥義は10.2%。環が1つ増えた分、以前より約1割小さい（ピンチで拡大できる）。
- 札は外周ノードと重ならない位置（盤面座標）に置く。ズームボタンは盤面の左下（右下は奥義が外枠に掛かるため空ける）。
- 魔法陣：三重の古金の外枠・目盛72・ルーン帯・大きな六芒星・環のガイド（点線）・方向の放射線（枝の色の破線）・基礎の環（基礎の色の二重線）。装飾はすべて当たり判定なし。

- 二択（どちらか1つだけ習得できるスキル）の表示（割符の印・分岐の門・比較表示・2回押し）は `スキルの二択UI設計.md` を参照。
