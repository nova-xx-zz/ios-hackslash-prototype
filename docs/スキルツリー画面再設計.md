## 3. 座標系とズーム（最重要）

- 盤面は **正方形1枚の `.tree-web-scene`**。枠（`.tree-web-viewport`）の短辺に合わせた一辺 `side` を JS が計算し、枠の中央に置く。
- SVG（魔法陣・ルーン・前提線。`viewBox="0 0 100 100"`、`preserveAspectRatio="none"`）と HTML（紋章・ノード・方向札。`left/top` を%）は **同じ0〜100の盤面座標** を共有する。
- scene の `font-size` を `side/100 px` にして **1em＝盤面1単位**。方向札の文字・余白は em、ノードは scene に対する%。
- **transform は scene にだけ** 掛ける：`translate(x, y) scale(k)`（`transform-origin` は中心）。追従するもの：剣紋章・魔法陣・ルーン・ノード・前提線・6方向の札。
- 固定するもの：背景・キャラ送り・タイトル・SP・タブ・職業見出し・ズームボタン・詳細カード・習得ボタン（scene の外）。
- 倍率：等倍1.0で盤面全体（札まで）が枠に収まる。最小0.8・最大2.6。ボタンは ×1.25 ／ ÷1.25、「全体」で1.0・中央。
- 基準点：ボタンは枠の中心、ピンチは2本指の中点、PCのホイールはカーソル位置（その点の盤面が動かないよう x, y を補正）。
- パンの範囲：盤面が枠からはみ出す分だけ（`max(0, (side×k − 枠)/2)`）。枠より小さい時（等倍・縮小）は中央に固定。
- iPhone Safari：盤面の枠は `touch-action:none`、`gesturestart` を止めて画面全体のズームを防ぐ。1本指は拡大中のみ移動。8px以上動いた直後の click は捨て、ノードの誤選択を防ぐ。
- 拡大位置は再描画（ノード選択・習得）で保持し、セーブしない。キャラ送りで別の仲間になったら等倍に戻す。画面回転などで枠の大きさが変わったら `ResizeObserver` で合わせ直す。

## 4. 盤面のデザイン

- 方向（画像3と同じ並び）：基礎（上）・猛攻（右上）・破砕（右下）・覇道（下）・鉄壁（左下）・装備（左上）。色：青・赤・琥珀・紫・鋼・緑。
- ノードは方向ごとに3つの環（半径18／28.25／38.5）に置く。中心寄り→外周の対応は `WARRIOR_WEB_LAYOUT`（ID・前提は正本のまま）。
- 前提線（実データの16本）の通り道：同じ方向は直線、同じ環なら環に沿う弧、剣撃突きからの4本は中心の導線（半径12.6）経由、方向をまたぐ線は環の間の導線（23.1／33.4）へ斜めに入って弧で回り込む。**どの線も無関係なノードの中心から4.5単位以上離れる**（テストで保証）。
- 線の色：習得済み＝枝の色で光る（魔力の流れ付き）、習得可能＝金、未解放＝枝の色を淡く、二択で封印＝赤錆の点線。
- ノードの色：習得済み＝枝の色の縁と光、習得可能＝金の縁と脈動、未解放＝鉄色（刻印は枝の色を淡く）、Lv不足＝封印石＋錠、二択封印＝赤錆＋鎖。選択中は金の点線リングが回る。形：パッシブ＝円／アクティブ＝菱形／装備＝六角／奥義＝八芒星。
- 魔法陣：三重の古金の外枠・目盛72・ルーン帯・大小の六芒星・環のガイド（点線）・方向の放射線（枝の色の破線）・中央の剣紋章（剣撃突き習得で灯る）。装飾はすべて当たり判定なし。
