# ios-hackslash-prototype

iPhone (Safari) で遊べるハクスラ要素のあるゲームのプロトタイプです。ビルド不要のバニラ HTML/CSS/JavaScript + Canvas で作られています。

## 遊び方

`index.html` をブラウザで開くだけで起動します。ローカルで試す場合は簡易サーバーを立ててください。

```
python3 -m http.server 8000
# http://localhost:8000 を iPhone Safari または PC ブラウザで開く
```

- 画面左下をドラッグ（仮想スティック）でキャラクターを移動
- 近くの敵には自動で攻撃（手動操作不要）
- 敵を倒すと XP オーブ / ゴールド / アイテム（コモン・レア・エピック）をドロップ
- XP を集めてレベルアップ、ウェーブをクリアするごとに敵が強化される
- HP が 0 になるとゲームオーバー。ベストウェーブは端末に保存されます

## 現状の設計方針（プロトタイプ版）

- 手動攻撃ではなく「近くの敵に自動攻撃」方式を採用し、移動の手触り検証を優先
- 見た目はプレースホルダー（図形ベース）。コアループの面白さの検証が目的
- 永続化はベストウェーブのみ（localStorage）。本格的なセーブ/アイテム所持は未実装
