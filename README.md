# ios-hackslash-prototype

iPhone (Safari) で遊べる、5人パーティ・オート戦闘のハクスラダンジョンクロールのプロトタイプです。ビルド不要のバニラ HTML/CSS/JavaScript で作られています。

> 特定タイトルの仕様を模倣したものではなく、「5人パーティ／速度依存のオート戦闘／転職システム」というジャンル共通の要素を、オリジナルの名称・データで実装したものです。ジャンルやゲームシステム自体は著作権の対象ではありませんが、固有名詞・グラフィック・文章表現は独自のものにしています。
>
> 開発経緯: v1はリアルタイム自動戦闘、v2はドラクエ/FF風のコマンド選択ATBバトルでした。今回は「速度ステータスに応じて行動間隔が変わる、5人フルオートのハクスラ」という要望に合わせて戦闘エンジンを作り直しています。

## 遊び方

`index.html` をブラウザで開くだけで起動します。ローカルで試す場合は簡易サーバーを立ててください。

```
python3 -m http.server 8000
# http://localhost:8000 を iPhone Safari または PC ブラウザで開く
```

- 所持キャラ全員が「ロスター」に入り、そこから最大5人を選んで「編成」＝戦闘パーティにする（ベンチのキャラは戦闘に出ない）
- キャラクターは「種族×ジョブ」でステータスが決まる。種族はプレイヤー用5種（ステータス倍率＋会心率/被ダメ軽減/吸収/経験値倍率のいずれか1つのパッシブを持つ）＋テイム対象のモンスター種族4種
- 戦闘は全員フルオート。各キャラは速度(SPD)に応じてたまるゲージが満タンになると自動で行動する
- 「パーティ編成」画面で、編成の入れ替え・ジョブ変更・サブアビリティ設定に加えて、各アビリティを個別にON/OFFできる。OFFにしたアビリティはオート戦闘のAIが選ばなくなる
- 「仲間を探す」ボタンで、ランダムな種族・ジョブ・名前の新規仲間をロスターに追加できる（ベンチ状態で加入）
- 敵を倒すとEXP・装備ドロップ（コモン/レア/エピック）を獲得
- ステージクリア後、そのステージで倒したテイム可能な敵（オーガ以外）がいれば成功判定を行い、成功すればモンスター種族の仲間としてロスターに加わる（失敗時はメッセージのみ）
- アビリティはキャラクターのレベルに応じて習得数が増える（各ジョブLv.1/5/10/15で1個ずつ、計4個）。レベルアップ時に習得すると結果画面に表示され、未習得の技はパーティ編成画面に「Lv.◯で習得」とグレー表示される
- バトル画面には再生速度(x1/x2)切り替えがあり、放置ゲーム感覚で周回できる
- 全滅するとゲームオーバー。ジョブ経験値・レベル・ロスターは引き継がれ、ステージ1からやり直せる（さいこう到達ステージはlocalStorageに保存）

## ファイル構成

- `index.html` — 画面構成（タイトル/パーティ編成/バトル/結果/ゲームオーバー）
- `css/style.css` — スタイル
- `js/data.js` — ジョブ・アビリティ・敵・種族・アイテムのデータ定義
- `js/game.js` — 画面遷移・オート戦闘AI・ATBエンジン・転職/装備ロジック

## オート戦闘AIのロジック（現状）

- ON状態かつレベルで習得済みのアビリティのうち、MPが足りるものを候補にする
- 回復技は「誰かのHPが減っている時だけ」候補に入れる（無駄撃ちしない）
- 候補があれば要求レベルが一番高い（＝強力な）技を優先、なければ通常攻撃
- 物理/魔法は残HPが一番低い敵を、回復は残HP割合が一番低い味方を自動選択

## 現状の設計方針（プロトタイプ版）

- 戦闘はDOMベース（Canvasは使わず、カード主体のUI）
- ジョブは3種（せんし/まほうつかい/そうりょ）、各ジョブにアビリティ4種（Lv.1/5/10/15で習得）
- キャラクターごとに装備スロットは1つのみ（武器・防具を区別しない簡易実装）
- 見た目はプレースホルダー（色付きの円）。システムの面白さの検証が目的

## 今後の検討事項

- ジョブの種類自体を増やすか（現状はせんし/まほうつかい/そうりょの3種）
- 種族の数・パッシブ効果の種類を増やすか（現状は1種族1パッシブのみ）
- AIの行動優先度を細かく設定できるようにするか（現状はON/OFFのみ）
- 装備スロットの拡張（武器/防具/アクセサリ）とインベントリ管理
- テイムしたモンスターにモンスター専用のアビリティを持たせるか（現状はせんしジョブを共用）
- マップ探索・ストーリー要素の追加（現状はステージ制の連戦のみ）
- 見た目・演出（スプライト、エフェクト、SE/BGM）の作り込み
- iOS ネイティブ化する場合の技術選定（Capacitor でラップ / Swift・Unity・Godotで書き直し 等）
