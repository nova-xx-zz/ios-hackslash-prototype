# ios-hackslash-prototype

iPhone (Safari) で遊べる、5人パーティ・オート戦闘のハクスラダンジョンクロールのプロトタイプです。ビルド不要のバニラ HTML/CSS/JavaScript で作られています。

> 特定タイトルの仕様を模倣したものではなく、「5人パーティ／速度依存のオート戦闘／転職システム」というジャンル共通の要素を、オリジナルの名称・データで実装したものです。ジャンルやゲームシステム自体は著作権の対象ではありませんが、固有名詞・グラフィック・文章表現は独自のものにしています。
>
> 開発経緯: v1はリアルタイム自動戦闘、v2はドラクエ/FF風のコマンド選択ATBバトルでした。今回は「速度ステータスに応じて行動間隔が変わる、5人フルオートのハクスラ」という要望に合わせて戦闘エンジンを作り直しています。

## 遊び方

`index.html` をブラウザで開くだけで起動します。ローカルで試す場合は簡易サーバーを立ててください。

```
python3 -m http.server 8000
# http://localhost:8000 を iPhone Safari または PC ブラウザで開く
```

- パーティは5人（せんし×2 / まほうつかい×2 / そうりょ×1が初期構成）
- 戦闘は全員フルオート。各キャラは速度(SPD)に応じてたまるゲージが満タンになると自動で行動する
- 「パーティ編成」画面で、ジョブ変更・サブアビリティ設定に加えて、各アビリティを個別にON/OFFできる。OFFにしたアビリティはオート戦闘のAIが選ばなくなる
- 敵を倒すとEXP・JP（ジョブポイント）・装備ドロップ（コモン/レア/エピック）を獲得
- JPを貯めるとそのジョブの上位アビリティが解放される（FF5風の転職システム）
- バトル画面には再生速度(x1/x2)切り替えがあり、放置ゲーム感覚で周回できる
- 全滅するとゲームオーバー。ジョブ経験値・レベルは引き継がれ、ステージ1からやり直せる（さいこう到達ステージはlocalStorageに保存）

## ファイル構成

- `index.html` — 画面構成（タイトル/パーティ編成/バトル/結果/ゲームオーバー）
- `css/style.css` — スタイル
- `js/data.js` — ジョブ・アビリティ・敵・アイテムのデータ定義
- `js/game.js` — 画面遷移・オート戦闘AI・ATBエンジン・転職/装備ロジック

## オート戦闘AIのロジック（現状）

- ON状態のアビリティのうち、MPが足りるものを候補にする
- 回復技は「誰かのHPが減っている時だけ」候補に入れる（無駄撃ちしない）
- 候補があれば要求JPが一番高い（＝強力な）技を優先、なければ通常攻撃
- 物理/魔法は残HPが一番低い敵を、回復は残HP割合が一番低い味方を自動選択

## 現状の設計方針（プロトタイプ版）

- 戦闘はDOMベース（Canvasは使わず、カード主体のUI）
- ジョブは3種（せんし/まほうつかい/そうりょ）、各ジョブにアビリティ2種のみに絞ってシステムの手触りを検証
- キャラクターごとに装備スロットは1つのみ（武器・防具を区別しない簡易実装）
- 見た目はプレースホルダー（色付きの円）。システムの面白さの検証が目的
