# ios-hackslash-prototype

iPhone (Safari) で遊べる、FFのジョブシステム × ドラクエ風ATBコマンドバトルのプロトタイプです。ビルド不要のバニラ HTML/CSS/JavaScript で作られています。

> 最初のバージョンはリアルタイム自動戦闘のハクスラでしたが、「ドラクエ/FF感のあるパーティ・転職要素のあるハクスラ」という方向性に合わせて、コマンド選択式のATBバトルに作り直しました。

## 遊び方

`index.html` をブラウザで開くだけで起動します。ローカルで試す場合は簡易サーバーを立ててください。

```
python3 -m http.server 8000
# http://localhost:8000 を iPhone Safari または PC ブラウザで開く
```

- パーティは3人（せんし/まほうつかい/そうりょをそれぞれ初期ジョブとして所持）
- 戦闘はATB（ウェイト制）: ゲージが満タンになったキャラのコマンドを選ぶ間、他の行動は止まる
- コマンドは「たたかう / ジョブ固有のとくぎ・まほう / ぼうぎょ」
- 敵を倒すとEXP・JP（ジョブポイント）・装備ドロップ（コモン/レア/エピック）を獲得
- JPを貯めるとそのジョブの上位アビリティが解放される（FF5風）
- 「ジョブ変更」画面でいつでも転職でき、他ジョブで解放したアビリティを1つ「サブアビリティ」として持ち越せる
- 全滅するとゲームオーバー。ジョブ経験値・レベルは引き継がれ、ステージ1からやり直せる（さいこう到達ステージはlocalStorageに保存）

## ファイル構成

- `index.html` — 画面構成（タイトル/ジョブ変更/バトル/結果/ゲームオーバー）
- `css/style.css` — スタイル
- `js/data.js` — ジョブ・アビリティ・敵・アイテムのデータ定義
- `js/game.js` — 画面遷移・ATBバトルエンジン・転職/装備ロジック

## 現状の設計方針（プロトタイプ版）

- 戦闘はDOMベース（Canvasは使わず、ボタン主体のJRPG UI）
- ジョブは3種（せんし/まほうつかい/そうりょ）、各ジョブにアビリティ2種のみに絞って「転職の手触り」を検証
- キャラクターごとに装備スロットは1つのみ（武器・防具を区別しない簡易実装）
- 見た目はプレースホルダー（色付きの円）。システムの面白さの検証が目的
